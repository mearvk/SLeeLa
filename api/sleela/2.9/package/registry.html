SLRegistry #sleela 2.5 (lib/registry/SLRegistry.sleela)

SLRegistry class

Defines SLRegistry — the OOD equivalent of the native Sleela Registry (registry/sleela_registry.*): a Windows-style hierarchical store of keys (an HKEY-like path tree), each holding settings and feature-flag values and, where relevant, a sealed provenance record (file/date/author/ version/hex-id/hash/originality-seal). A fresh SLeeLa install seeds a baseline registry that is reviewable from a terminal (sleela registry) or a Sleela terminal program. Persistence and SHA-256/seal computation cross the native bridge; this class is the Sleela-side model + review. Mirrors: sl_reg_create, seed_defaults, key_create, the set_* family, provenance_set, save, load, and review. The native OP for a registry service is reserved for a future opcode; today the terminal 'sleela registry' is the review surface. Family: registry. Composes SLRegistryKey, SLRegistryValue, SLRegistryProvenance.

Carries the standard Metadata Class record — eleven catalogued provenance attributes (version, id, author, date, copyright, trademark, corporation, origin, birth date, science rating, national schedule) with matching get/set accessors. These are omitted from the tables below for brevity.

SLRegistryKey #sleela 2.5 (lib/registry/SLRegistryKey.sleela)

SLRegistryKey class

Defines SLRegistryKey — the OOD equivalent of a native registry key (a node in the HKEY-style path tree). A key is named by its full path ("A/B/C"), holds a bounded set of SLRegistryValue entries (settings and feature flags), and may carry one SLRegistryProvenance record. The surface has no arrays, so the value set is numbered fields (the SLVM binding-table convention). Mirrors: the native RegKey (path + values + optional provenance). Family: registry. Composes SLRegistryValue, SLRegistryProvenance; held by SLRegistry.

Carries the standard Metadata Class record — eleven catalogued provenance attributes (version, id, author, date, copyright, trademark, corporation, origin, birth date, science rating, national schedule) with matching get/set accessors. These are omitted from the tables below for brevity.

SLRegistryProvenance #sleela 2.5 (lib/registry/SLRegistryProvenance.sleela)

SLRegistryProvenance class

Defines SLRegistryProvenance — the OOD equivalent of a native registry provenance record (registry/sleela_registry.* struct sl_reg_provenance). It makes a registry entry self-describing and verifiable: the tracked file's name, date, author, version, a stable hex id, the SHA-256 of its content, and an ORIGINALITY SEAL. The seal is a SHA-256 over (hexId | version | hash | author); if any of those is altered, verify() reports the seal broken. The actual hashing crosses the native bridge (the host computes SHA-256); this class is the record + seal check. Mirrors: sl_reg_provenance + sl_reg_seal/sl_reg_seal_verify. Family: registry. Attached to an SLRegistryKey.

Carries the standard Metadata Class record — eleven catalogued provenance attributes (version, id, author, date, copyright, trademark, corporation, origin, birth date, science rating, national schedule) with matching get/set accessors. These are omitted from the tables below for brevity.

SLRegistryValue class

Defines SLRegistryValue — the OOD equivalent of a native registry value (registry/sleela_registry.* : a name -> typed scalar). A value holds one setting or feature flag under a key: a string, an int, or a boolean, tagged by kind. It is the leaf the registry stores and the terminal review renders.
