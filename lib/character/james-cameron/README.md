# James Cameron — SLeeLa Character Models

This directory contains SLeeLa source models for a public-figure profile and a traceable record of **publicly documented professional events** involving filmmaker James Cameron.

## Files

- `JamesCameronHuman.sleela` — a minimal human/person profile using public biographical facts.
- `JamesCameronHumanEvent.sleela` — a structured record for a public professional event, with source and confidence fields.
- `JamesCameronAdvancedTrace.sleela` — an audit-oriented trace over explicitly supplied public event records.

## Boundaries

“Advanced Trace” means provenance, chronology, and validation of public records supplied to the model. It does not perform live location tracking, private surveillance, identity resolution, or collection of private communications. Do not populate these models with sensitive personal data or unverified allegations. Event records should include a source URL, publication date, and verification status; unknown details remain unknown.

These files are source-model examples, not a claim that James Cameron has authorized or reviewed them.
