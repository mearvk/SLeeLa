# SLeeLa — BANKS2.md

## HTTP 3.0 National Banking, Economic & Historical Registry

This is a parallel currency-population copy of the national banking/economic registry. It preserves the existing `BANKS.md` data model while providing a separate file for the online currency-data pass.

## Currency Data Pass

Currency assignments use three-letter ISO 4217-style currency codes. The mapping is based on the SLeeLa known-good currency dataset and cross-checked against current country/currency reference data.
