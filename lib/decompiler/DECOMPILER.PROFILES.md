## BASIC_COMPLETE

- explicit source language/version
- expected input validation
- format and architecture detection
- weighted OS/ABI discernment
- decoder and CFG
- SLeeLa IR
- basic semantic analysis
- reconstruction
- fractional-input policy
- evidence-preserving output
- VM readiness validation

## ADVANCED_TOTAL

Adds multi-pass architecture and ABI analysis, deep symbol/type/data-flow recovery, module dependency resolution, conflicting-evidence analysis, provenance and confidence records, cross-reference reports, richer reconstruction, strict capability and VM validation, and deterministic diagnostics.

The advanced profile increases analysis depth; it does not turn uncertain inference into fact.
