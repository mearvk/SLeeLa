# professional — graded, ranked, role-cast work

Examples that put the package to professional use: scoring work with the
sophistication circuit and ranking it, and casting a cohort of professional
roles against the grader.

| Topic | Folder | Examples | Shows |
|-------|--------|----------|-------|
| Sophistication grading | [`sophistication-grading/`](sophistication-grading/) | `grading-primer.sleela`, `professionals-demo.sleela` | the scoring modules and the ranking of winning / losing / grader / absolute sets A–D; a cohort of six professional roles scored and ranked |

Run from the repository root, e.g.:

```sh
./working-binaries/sleela run lib/advantage/examples/professional/sophistication-grading/professionals-demo.sleela
```
