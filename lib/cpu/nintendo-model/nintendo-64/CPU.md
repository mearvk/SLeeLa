# Nintendo 64 — CPU Reference

## Hardware Profile

| Field | Reference |
|---|---|
| System | Nintendo 64 |
| CPU | NEC VR4300, MIPS III-derived 64-bit RISC |
| CPU clock | 93.75 MHz |
| Main RAM | 4 MB RDRAM |
| Expansion RAM | +4 MB with Expansion Pak |
| Launch | 1996 |
| Launch MSRP | $199.99 US |

## SLeeLa Representation

The Nintendo 64 profile models its 64-bit MIPS-derived CPU, RDRAM configuration, bus behavior, and execution timing as a historical hardware target.

## Compatibility Intent

The profile is suitable for architecture research and emulator-style CPU modeling. Expansion Pak memory is represented as an optional configuration rather than a requirement.

## Cost Note

The price is the historical US launch MSRP.
