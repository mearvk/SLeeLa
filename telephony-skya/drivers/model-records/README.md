# Model Driver Records

Model records are the evidence and identity layer for Skya's model-specific drivers.

Each record distinguishes identity, transport, capabilities, platform behavior, official vendor software, and test status.

A catalog entry does not imply certification. Exact VID/PID and HID mappings must be verified against physical hardware before being treated as authoritative.
