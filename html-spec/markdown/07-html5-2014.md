## Summary

HTML5 was a landmark release that modernized HTML into an application platform. It originated from the **WHATWG** (formed in 2004 by browser vendors frustrated with the XHTML 2.0 direction) and was published as a formal W3C Recommendation in 2014. It explicitly defines **error-handling / parsing rules**, so all conforming browsers build the same DOM from the same (even malformed) markup.

## Key features

- **Semantic structure**: `<header>`, `<footer>`, `<nav>`, `<article>`, `<section>`, `<aside>`, `<main>`, `<figure>`
- **Native multimedia**: `<audio>`, `<video>` (no plugins); `<canvas>` for 2-D drawing; inline SVG/MathML
- **Rich forms**: new `<input>` types (`email`, `url`, `date`, `range`, `color`…), `placeholder`, `required`, built-in validation
- **JavaScript APIs** bundled into the platform: Web Storage, `fetch`/XHR, Web Workers, Geolocation, Drag-and-Drop, History API, WebSockets, offline/app cache
- A single, simple doctype: `<!DOCTYPE html>`
- Defined explicit, interoperable **parsing rules** for the first time

## Significance

Ended the plugin era (Flash/Java applets), made the browser a full application runtime, and reunified the HTML/XHTML split. It set up the subsequent incremental W3C revisions (5.1, 5.2) and, ultimately, the move to a single WHATWG Living Standard.
