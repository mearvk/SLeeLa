# SLeeLa Regex Natural Form

Version: 1.1.0-dev

A readable, finite regex language for users. Natural Form provides memorable names such as `digit`, `letter`, `optional`, `many`, `some`, `begin`, `end`, and named groups such as `<user: letter+>`.

Symbolic aliases remain available for compact patterns. Natural Form is parsed into a canonical representation before reaching a regex backend.
