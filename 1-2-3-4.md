# Synchro 1-2-3-4

## 1 — Protocol
16-byte SYNC packet, network-order sequence/timestamp, strict validation, local RTT, timeout loss, nearest-rank percentile.

## 2 — Integration
C prepare/ack/timeout/stats ABI, C++ RAII wrapper, Java UDP/SLA boundary, existing VM Synchro operations.

## 3 — Verification
C/C++/Java suite covers positive and negative protocol paths, statistics windows, loss/delivery accounting, and controlled Java UDP loopback.

## 4 — Release
GitHub Actions executes the standalone suite on Ubuntu for main/master. macOS and Windows remain release-platform verification work.
