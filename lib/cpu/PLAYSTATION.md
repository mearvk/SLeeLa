# PlayStation CPU Profiles

SLeeLa CPU library profiles for the Sony PlayStation console generations.

| Directory | Platform | Principal CPU | Clock | Main RAM |
|---|---|---|---:|---:|
| `playstation-1` | PlayStation | MIPS R3000A-based | 33.8688 MHz | 2 MB |
| `playstation-2` | PlayStation 2 | Emotion Engine | 294.912 MHz | 32 MB RDRAM |
| `playstation-3` | PlayStation 3 | Cell Broadband Engine | 3.2 GHz | 256 MB XDR |
| `playstation-4` | PlayStation 4 | AMD Jaguar 8-core | 1.6 GHz | 8 GB GDDR5 |
| `playstation-5` | PlayStation 5 | AMD Zen 2 8-core | up to 3.5 GHz | 16 GB GDDR6 |

These are historical hardware reference profiles for SLeeLa architecture research, simulation, and platform-aware workload modeling. They do not imply proprietary console firmware or software is included.
