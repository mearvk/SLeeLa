# Skya Driver Brand Matrix

Initial driver targets:

- Yealink — MP45, MP50, UH42, UH44, WH64, WH68
- Poly — Blackwire, Savi, Voyager
- Jabra — Biz, Evolve, SPEAK2
- Grandstream — GUV, GXP21xx, GRP26xx
- EPOS / Sennheiser — IMPACT, SDW, ADAPT
- Logitech — Zone, H570e, SPEAK
- Fanvil — XU, V, X210i
- Snom — A330D, A330M
- Cisco — 320 series headsets

The normalized model/family list is in `brands/versions/README.md`.

These are driver targets, not blanket compatibility guarantees. The native runtime must probe the actual device and operating-system transport before enabling optional controls.
