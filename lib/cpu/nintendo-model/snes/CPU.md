# Super Nintendo Entertainment System (SNES) — CPU Reference

## Hardware Profile

| Field | Reference |
|---|---|
| System | Super Nintendo Entertainment System (SNES) |
| CPU | Ricoh 5A22, 65C816-derived |
| CPU clock | ~3.58 MHz maximum |
| Main RAM | 128 KB |
| Video RAM | 64 KB |
| Launch | 1990 Japan; 1991 North America |
| Launch MSRP | $199.99 US |

## SLeeLa Representation

The SNES profile represents the 16-bit 65C816-derived CPU, memory map, timing, and console-oriented device model for research and emulation-oriented CPU work.

## Compatibility Intent

This profile may be paired with `SLCPU`, `SLRAM`, `SLMMU`, `SLBus`, and instruction-model components to represent an SNES-class machine.

## Cost Note

The price is the historical US launch MSRP.
