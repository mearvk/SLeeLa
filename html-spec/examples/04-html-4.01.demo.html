HTML 4.01 "Cougar" (1999) — Use-Case Demonstration

Date: 2026-10-25

This document demonstrates the elements HTML 4.01 added (generic inline containers, inline quotes, abbreviations, edits, bidi, the full accessible table model, rich forms, generic objects, and frames) in their usual use cases. Each example states whether it still performs as expected in a modern browser: ✓ Yes, or ✗ No.

Use case 1 — Generic inline container

Title: A span hook  |  Date: 2026-10-25

The temperature is vingt degrés today.

Performs as expected: ✓ Yes — <span> was new in HTML 4.0.

Use case 2 — Inline quotation and abbreviations

Title: Quote, abbreviation, acronym  |  Date: 2026-10-25

She said the web is for everyone. We use HTML and W3C standards.

Performs as expected: ✓ Yes for <q> and <abbr>. ✗ No for <acronym> — obsolete; use <abbr>.

Use case 9 — Framesets

Title: Multi-frame layout  |  Date: 2026-10-25

A Frameset document replaces <body> with:

<frameset cols="25%,75%">
  <frame src="menu.html">
  <frame src="content.html">
</frameset>

(Shown as escaped markup, not emitted live, because it cannot coexist with a <body>.)

Performs as expected: ✗ No — frameset/frame/noframes are obsolete and removed from HTML; use <iframe> or server-side composition.

Summary: Nearly all of HTML 4.01's additions (span, q, abbr, ins/del, bdo, the full table model, rich forms, object, iframe) perform as expected. The exceptions are <acronym>, the summary attribute, and framesets — all obsolete.
