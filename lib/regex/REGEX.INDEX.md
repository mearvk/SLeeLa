# Regex Library Index

The regex library is intentionally broader than Subject and System. It includes the complete SLeeLa-facing object family: Regex, RegexPattern, RegexSubject, RegexSystem, RegexScanner, RegexCompiler, RegexMatcher, RegexMatch, RegexCapture, RegexReplacer, RegexSplitter, RegexDialect, RegexCapability, RegexFlags, RegexOptions, RegexIterator, RegexReplacement, RegexLiteral, RegexValidator, RegexResult, RegexError, and RegexEngine.

Every object is a separate SLeeLa 1.3 source file so IDE indexing, compiler diagnostics, testing, and library discovery can operate per object.
