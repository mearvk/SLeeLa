# Sega Mega-CD / Sega CD — CPU Reference

| Field | Reference |
|---|---|
| Main CPU | Motorola 68000 |
| CPU type | 16/32-bit CISC |
| Main clock | ~12.5 MHz |
| Base system | Mega Drive / Genesis |
| Launch | 1991 Japan |
| Media | CD-ROM |

The Mega-CD/Sega CD is a CD-ROM expansion of the Genesis/Mega Drive architecture, with additional 68000-family processing capability.
