## Summary

HTML 2.0 was the **first formal HTML specification** — the first version blessed by a standards body (the IETF). It codified the common practice of the early-1990s browsers (notably NCSA Mosaic) into a single document with a proper SGML DTD. "2.0" was chosen to distinguish it from the many informal "1.x" documents in circulation; there was never a formal HTML 1.0 standard.

## Key features

- The `<html>`, `<head>`, `<body>` document structure
- **Forms**: `<form>`, `<input>`, `<select>`, `<option>`, `<textarea>` — enabling interactive data submission
- `<img>` for inline images (with `src` and `alt`)
- Formalized a full SGML DTD and a declared character set (ISO-8859-1 / Latin-1)
- Consolidated headings, lists, anchors, and text-level elements from earlier practice

## Significance

The baseline that defined "standard HTML" for years. Later IETF work (HTML 3.0) stalled, and leadership of HTML passed to the W3C.
