# Atari Jaguar CD — CPU Reference

| Field | Reference |
|---|---|
| Host CPU | Motorola 68000 |
| CPU clock | 13.295 MHz |
| Main RAM | 2 MB |
| Additional media | CD-ROM expansion |
| Launch | 1995 |
| Launch price | Historical Jaguar CD add-on pricing |

The Jaguar CD is modeled as an expansion of the Jaguar CPU/memory architecture rather than as a separate replacement CPU.
