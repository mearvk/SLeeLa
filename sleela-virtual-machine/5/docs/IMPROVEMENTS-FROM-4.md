# Improvements from SLVM/4 to SLVM/5

| Area | /4 | /5 |
|---|---|---|
| Distributed execution | Authenticated | Transaction-aware and recoverable |
| Policy | Versioned direction | Immutable hashed snapshots |
| Attestation | Distributed evidence | Reproducible build/policy evidence |
| Audit | Correlated | Durable checkpoints |
| Objects | Leases | Lease + transaction context |
| Recovery | Fault containment | Integrity-checked checkpoints |
| Determinism | Replay policy | Replayable execution evidence |
| Certificates | Trust exchange | Lifecycle and rotation policy |
| Resolver | Authenticated provenance | Provenance retained in recovery/audit |
| Compatibility | Negotiated | Negotiated with build/policy identity |
