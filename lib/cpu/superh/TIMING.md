# SuperH Timing

Tracked events:

- instruction fetch;
- decode;
- register access;
- integer execution;
- multiply/accumulate;
- branch delay;
- load/store;
- cache/TLB;
- FPU/DSP;
- exception;
- interrupt.

SH-4 provides a five-stage pipeline and maximum two-instruction-per-cycle execution in its superscalar implementation. citeturn1search20

Earlier profiles are not assigned SH-4 timing characteristics.
