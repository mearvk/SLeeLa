# Language Reference

The Sleela language is a small, Java-like subset compiled by **Sleelvac™** (currently 1.4) and executed on the C/C++ core. This page is the practical reference; the normative documents are `COMPILER.md`, `SOURCE.md`, `SLEELA.md`, and `VERSION.md`.

> Supported `.sleela` syntax versions: **1.0 – 1.1**.

---

## Program structure

A program is one or more `class` declarations. There are **no top-level statements** — code lives in methods. Execution starts at a `main()` method.

```sleela
#sleela 1.0

class Greeter {
    static String who() { return "Sleela"; }

    void main() {
        print("Hello, " + who() + "!");
    }
}
```

- `import <module>;` lines (native modules) come before class declarations.
- A class holds **fields** and **methods**; `static` marks class-level members.

---

## Keywords & types

**Keywords:** `class`, `static`, `import`, `if`, `else`, `while`, `for`, `return`, `print`, `true`, `false`, `null`.

**Types:**

| Type | Meaning |
|---|---|
| `int` | 64-bit integer |
| `double` | floating point |
| `boolean` | `true` / `false` |
| `String` | text; `+` concatenates |
| `void` | no return value |

`print(x)` writes a line to standard output. `+` concatenates when either side is a `String` (Java-like).

---

## Statements & expressions

```sleela
int i = 0;                    // declaration
i = i + 1;                    // assignment
if (i < 10) { ... } else { ... }
while (i < 10) { i = i + 1; }
for (int k = 0; k < n; k = k + 1) { ... }
return expr;
```

Operators: arithmetic `+ - * / %`, comparison `== != < <= > >=`, logical `&& || !`, unary `-`.

---

## The `#sleela` version pragma

The first line may declare the syntax version:

```sleela
#sleela 1.1
```

- The compiler accepts **1.0** through **1.1**.
- **Network built-ins require 1.1.**
- A missing pragma emits a warning and assumes **1.0**.
- Versions newer than the compiler's max, or malformed pragmas, are rejected with a clear diagnostic.

## Native modules

Import a native module to call its functions with a `module.function(...)` syntax. Available modules:

`math`, `physics`, `economics`, `excel`, `json`, `crypto`, `net`.

Physics and Economics require `import math` (declare it explicitly). Financial functions are provided by the `financial` integration (see below).

```sleela
#sleela 1.0
import math;
import economics;

class Model {
    static double grow() {
        return economics.future_value(1000.0, 0.05, 10.0);
    }
    void main() { print(grow()); }
}
```

### Financial functions

The financial library lowers `financial.*` calls to the native math kernels:

`future_value`, `present_value`, `annuity_present`, `annuity_future`, `npv4`, `bond_price`, `capm`, `wacc`, `determinant2`, `solve2x2_x`, `solve2x2_y`, `quadratic_discriminant`, `quadratic_root_plus`, `quadratic_root_minus`, `ratio`.

```sleela
#sleela 1.0
import math;
import financial;

class Desk {
    void main() {
        print(financial.future_value(1000.0, 0.05, 10.0));   // 1628.89
        print(financial.capm(0.04, 1.2, 0.10));              // 0.112
    }
}
```

## Conducted methods (the object catalog)

Sleela exposes the `SHEET.sheet` catalog as *conducted methods* — queries over the catalog of common system objects:

| Method | Returns |
|---|---|
| `insight(Object)` | the object's one-line gloss |
| `role(Object)` | the object's conduct role |
| `congruent(A, B)` | whether two objects are directly connectable |
| `route(A, B)` | the connection route between two objects |
| `sysdepth()` | the system depth invariant (**3024**) |
| `degreemax()` | the max complexity degree (**4**) |

See `examples/conduct.sleela`.

---

## Networking (syntax 1.1+)

Network built-ins lower to the core socket ABI (`LISTEN / ACCEPT / CONNECT / SOCKREAD / SOCKWRITE / SOCKCLOSE`):

`listen`, `accept`, `connect`, `sockread`, `sockwrite`, `sockclose`.

See `examples/network_echo.sleela`. (These require `#sleela 1.1`.)

---

## Concurrency

The core is thread-friendly; see `examples/threads.sleela`. Threading maps onto the catalog's concurrency objects (`Thread`, `Lock`, `Future`, `Join`, …), which Nordshrift renders per target.

---

## The `.sleela` file — a Wrapper™

Every `.sleela` file is a **Wrapper™**: the program unit that carries the SL-META-0001 metadocument addend. It also supports a configurable **Sigil QR code** and a deterministic **248×48 steganographic frame**, generated by the dependency-free tool in `tools/sigil/`. See `SLEELA.md`.

## Compiler commands (Sleelvac™)

```sh
sleela run     <file.sleela>              # compile + run on the core
sleela run     <program.sleela>           # run a prebuilt Core artifact
sleela run     <file.xclass> [more...]    # ingest SecureJDK 28 .xclass and run
sleela compile <file.sleela> -o <out.sleela>   # persistent runnable artifact
sleela check   <file.sleela>              # parse/validate only
sleela xclass  [--run|--emit|--info] <file.xclass> [more...]
sleela version
```
