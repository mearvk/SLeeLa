SLCadCommand (lib/autocad/SLCadCommand.sleela)

SLCadCommand class

Defines SLCadCommand -- one recorded, reversible edit the AutoCAD Creator(TM) applied to a document. Every creation (line/text/dim/room) and every alteration (move/reshape/relabel/restyle/delete) is captured as a command so the Creator can keep an audit trail and offer undo: a command remembers its verb, the id of the entity it affected, and the "before" values needed to reverse it (prior endpoints, prior label/layer, prior alive flag). This keeps editing a first-class, inspectable operation rather than an opaque mutation -- which is exactly what makes a creator (as opposed to a one-shot renderer) possible. Family: autocad. SLeeLa owns the edit history; a command is a plain record, replayed/reversed against an SLCadDocument.

Carries the standard Metadata Class record — eleven catalogued provenance attributes (version, id, author, date, copyright, trademark, corporation, origin, birth date, science rating, national schedule) with matching get/set accessors. These are omitted from the tables below for brevity.

SLCadCreator (lib/autocad/SLCadCreator.sleela)

SLCadCreator class

Defines SLCadCreator -- the AutoCAD Creator(TM): the SLeeLa facade a front end drives to CREATE and ALTER 2D AutoCAD documents and then SAVE them as DXF. It owns an editable SLCadDocument, a current selection (the id a GUI tool acts on), the active layer, and a bounded command history so every create/alter/delete is recorded and undoable. Creation builders (line/wall/room/dim/note) each record a CREATE command; alteration verbs (move/reshape/relabel/restyle/delete) snapshot the prior state before mutating so undo() can reverse them. save() asks the document for the full DXF text. This is the authoritative editing brain; the SleelaUI GUI (autocad/creator) is only a surface that issues these intents and previews the result -- JavaFX never computed geometry here, and neither does SleelaUI. Family: autocad. SLeeLa owns the document, the edits, and the history; a front end selects, creates, alters, and saves through this object.

SLCadEntity (lib/autocad/SLCadEntity.sleela)

SLCadEntity class

Defines SLCadEntity -- a single, individually addressable 2D drawing entity in the editable AutoCAD model. Where SLCadModel accumulates geometry append-only into a DXF string (good for one-shot rendering), an SLCadEntity is a mutable record the AutoCAD Creator(TM) can select, move, re-layer, re-label, and delete after it has been created. Each entity has a stable id, a kind (line / text / dim), a layer, two points (p1,p2 -- the second is unused for a point-anchored TEXT), a text value (for TEXT and the measured label of a DIM) and a text height, plus an "alive" flag so a delete is a soft tombstone that keeps ids stable. This is the atom the editable SLCadDocument stores and the SLCadCanvas paints. Family: autocad. SLeeLa owns the geometry and every edit to it; a front end only issues create/alter/move/delete intents.
