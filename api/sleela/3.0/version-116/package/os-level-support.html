SLOsRuntimeStatus #sleela 2.5 (lib/os-level-support/SLOsRuntimeStatus.sleela)

SLOsRuntimeStatus class

Status values for the in-process OS-support runtime (event-hook registry and cooperative task queue). These numeric values match the slosh_status enum in lib/os-level-support/include/sleela_os_support.h and the osls_runtime_status enum in os-level-support/runtime/osls_runtime.h. This is a distinct status space from the core osls_* ABI (see SLOsSupportStatus): the runtime adds OUT_OF_MEMORY, CAPACITY, BUSY and CALLBACK_FAILED and has no BUFFER_TOO_SMALL, SYSTEM_ERROR or UNSUPPORTED value.

Carries the standard Metadata Class record — eleven catalogued provenance attributes (version, id, author, date, copyright, trademark, corporation, origin, birth date, science rating, national schedule) with matching get/set accessors. These are omitted from the tables below for brevity.
