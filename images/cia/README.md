# CIA Image Assets

This directory contains image assets and visual materials related to the Central Intelligence Agency (CIA) for the SLeeLa project.

## Organization

- Use descriptive, lowercase filenames with hyphens.
- Document each asset's purpose, source, and applicable license or attribution.
- Distinguish official public materials, historical/archive images, editorial images, and illustrative or generated artwork.
- Do not imply that unofficial artwork is an official CIA publication or insignia.
- Do not commit confidential, classified, or unlicensed material.

## Asset Index

Record each asset's filename, short description, source, and rights information here as assets are added.
