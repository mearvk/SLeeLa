# Unit 3 (Children): If This, Then That

**You will learn:** what a rule is, when it is broken, and when you cannot tell.
**Use with:** [lesson 1, registry intake](../series/README.md).

## Rules

A rule says: **if** one thing is true, **then** another thing must be true.

A rule is **broken** only when the "if" part is true and the "then" part is
false. If the "if" part is false, the rule is not broken. It just does not
apply.

Our shelf rule: **if a thing is in a box, then the box is on the shelf.**

## Part 1: Is the rule broken?

The shelf has a red box (ball inside), a blue box (book inside) and a block.

1. The ball is in the red box, and the red box is on the shelf.
2. The block is not in a box.
3. A kite is in a box, but the box is on the floor.

## Part 2: The Instructor rule

The Device Instructor has this rule for adding things to its list:
**if a thing is added, then its box must already be on the list.**

4. Add "ball" in the "red box", but the red box is not on the list yet.
   Is the rule broken? What does the Instructor do?
5. Add the "red box" to the shelf first, then add the ball. What happens?
6. Add "ball" in the "blue box", but the ball is already in the red box. The
   blue box is on the list. Is it allowed? (A thing may be in only one place.)

Run lesson 1 with a grown-up and find the line for each case.

## Part 3: Rules you can check

7. Make a rule about your own toys. Say when it is broken and when it is not.

## Answer key

1. The rule holds. 2. The rule is not broken; the "if" part is false.
3. The rule is broken. A thing is in a box, and the box is not on the shelf.
4. The rule would be broken, so the Instructor says "refused: carrier is not the
   field and not a registered noun".
5. The red box goes on the list, then the ball is accepted.
6. Not allowed. A thing may have only one place, so the Instructor says "noun
   already has a carrier (one place only)". Both the box being on the list and
   one place only must be true.
7. Any rule is good if you can name a case that breaks it and a case that does not.
