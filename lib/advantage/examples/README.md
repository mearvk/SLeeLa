# lib/advantage/examples — worked SLeeLa examples

Source examples that exercise the `advantage` package (the Sequitur onion model
and its `math/`, `physics/`, `integration/`, `grading/`, `output/` subjects)
from SLeeLa itself.

| Folder | Purpose |
|--------|---------|
| [`professionals/`](professionals/) | Examples cast for professional roles — graded, advantaged work by professionals. |

Each example is a runnable `.sleela` unit (`sleela run <file>`); the
subfolder's siblings auto-link with no imports needed. These are illustrative
source examples, not part of the library's class vocabulary surface.
