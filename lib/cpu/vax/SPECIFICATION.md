# DEC VAX Specification

## Programmer state

- R0-R11 general-purpose registers
- R12 argument pointer
- R13 frame pointer
- R14 stack pointer
- R15 program counter
- PSW condition and control state

VAX instructions use variable-length encodings and extensive operand/addressing modes.

## Architectural facilities

- byte, word, longword and larger data operations
- integer arithmetic
- floating point
- character/string operations
- procedure calls and returns
- memory-management/protection facilities
- interrupt and exception handling
- privileged system state

Exact floating-point and memory-system capabilities vary by VAX generation.
