SLeeLa Decompiler API

Max Rupplin - MEARVK LLC - 2026

Static analysis and refactoring API for PE/DLL/SYS, ELF, Mach-O and raw binary artifacts.

ClassRole
ArtifactImmutable bytes, identity, format and architecture.
DecoderInstruction and operand recovery.
ControlFlowGraphBasic blocks and control-flow edges.
AnalyzerFunction candidates and higher-level analysis.
ModuleSLeeLa Intermediate Representation container.
FunctionRecovered function and provenance.
OperationTyped SLIR operation.
ValueIR value and type handle.
VmBounded deterministic SLIR validation runtime.
VmTrapExplicit runtime failure record.

Design

Input artifacts are never executed or modified. Generated C/C++ is a separate refactoring product and carries provenance back to the analyzed artifact.
