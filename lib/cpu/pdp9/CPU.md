# DEC PDP-9 CPU

SLeeLa profile for the Digital Equipment Corporation PDP-9, a 18-bit member of DEC's later PDP minicomputer line.

- **Status:** profile-driven functional foundation; not a cycle-accurate emulator.
- **Word size:** 18 bits.
- **Execution model:** accumulator-centered instruction execution with memory, arithmetic/logical, control-flow, and I/O operations.
- **Configuration:** memory capacity, address behavior, instruction options, peripheral map, and timing are machine-profile settings.
- **Family separation:** PDP-9 behavior must not be assumed identical to PDP-4, PDP-7, PDP-10, or the 12-bit PDP-5/PDP-8.

Unknown or variant-dependent details remain explicitly unspecified until supported by a reliable PDP-9 reference.
