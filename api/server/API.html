Discord-1™ — SLeeLa sleelas API

Discord-1™ is the programmatic name for sleelas, the compiled native launcher for the SLeeLa Server Edition reference program.

Reference

The launcher starts server-edition/src/Server.sleela through the normal compiled sleela engine. Server semantics therefore remain in the authoritative SLeeLa source rather than being duplicated in the launcher.

Runtime contract

  • Locates the installation root or honors SLEELA_ROOT.
  • Locates the engine or honors SLEELA_BIN.
  • Creates server-edition/inbox and server-edition/state.
  • Uses an atomic directory lock and owner-process check to prevent duplicate server instances.
  • Preserves --tick, --foreground, and --help.
  • Passes the trusted SHA-256 manifest environment to the engine when the repository manifest is present.
  • Does not open a public listening socket itself.

NAT-aware deployment API

The compiled launcher includes nat_aware.h and nat_aware.cpp. The API defines five explicit deployment modes: direct, port-forward, ipv6, outbound, and relay.

Configuration is validated from the SLEELA_NAT_* environment variables. Outbound and relay modes require a rendezvous endpoint and TLS. --nat-plan prints the deterministic plan without opening sockets or changing router state.
