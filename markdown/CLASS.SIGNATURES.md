# SLeeLa Class Signatures

**Revision:** 1.0 — 2026-10-08

This document is the human-readable signature index for newly promoted Master
Class families. The authoritative complete symbol list remains
`lib/LIBRARY.SYMBOLS.md`; `markdown/CLASS.INVENTORY.md` is the count and
inventory authority.

## Amazon Workforce & Organization

| Class | Signature | Purpose |
|---|---|---|
| SLHiringManager | `decide(role, fit)` | criteria-based hiring review |
| SLFiringManager | `decide(reason, documented)` | documented termination review |
| SLWorkforceManager | `plan(role, capacity)` | staffing and training planning |
| SLCollegeManager | `courseFor(trainingNeed)` | education and course routing |
| SLFashionGearManager | `outfit(role, required)` | lawful role gear/style routing |
| SLGearManager | `assign(person, gear)` | equipment assignment |
| SLFriendsManager | `connect(a, b)` | healthy team connection support |
| SLWorkplaceLaw | `check(jurisdiction, action)` | policy/counsel escalation |
| SLInterTrireManager | `transition(person, voluntary)` | succession/redeployment/retirement review |
| SLRetirementManager | `plan(voluntary, readiness)` | retirement transition planning |
| SLTalentManager | `develop(skill, mentorship)` | development and mentoring |
| SLOrganizationManager | `team(role, manager)` | team/role organization |

All employment-changing actions are advisory and require appropriate human
review. No protected characteristic or intelligence score is an input to an
automated employment outcome.
