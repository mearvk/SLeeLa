# Wi-Fi 6

**SLeeLa Wi-Fi 6 Foundation**

The `/wi-fi-6` directory is reserved for SLeeLa's Wi-Fi 6 work: a common place to document the wireless networking standard, supported capabilities, interoperability considerations, security requirements, and how SLeeLa components may use compatible wireless networks.

The directory name **Wi-Fi 6** identifies the requested generation. Specifications and implementation details must distinguish verified standard requirements from proposed SLeeLa design choices.

## Scope

- Protocol and capability overview for Wi-Fi 6.
- Compatibility and interoperability notes.
- Security and configuration guidance.
- Implementation plans, test cases, and platform considerations.

## Status

Initial, reserved foundation. This directory establishes a place for future documentation; it does not claim that a complete protocol implementation exists. Add concrete specifications, source, and tests after explicit design and review.
