# SLVM/7 Build Layout

Portable build targets:
- linux/ — GCC/Clang and GNU Make
- windows/ — MSVC or MinGW-compatible environment
- macos/ — Apple Clang and Make

The canonical build entry point remains the SLVM/7 Makefile.
