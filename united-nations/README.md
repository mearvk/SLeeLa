# United Nations

This directory is the top-level workspace for United Nations–related SLeeLa source, reference materials, data, and examples.

## Suggested organization

- `README.md` — scope, conventions, and navigation for this directory.
- `docs/` — background notes and technical documentation.
- `data/` — sourced reference data, with provenance and retrieval dates.
- `examples/` — SLeeLa examples and demonstrations.
- `src/` — implementation source, grouped by topic or subsystem.

## Contribution conventions

- Keep United Nations reference material distinct from executable implementation code.
- Record sources, dates, and applicable licenses for external reference data.
- Avoid committing secrets, credentials, or personal data.
- Update this README as the directory structure grows.
