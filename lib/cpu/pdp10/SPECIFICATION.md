# DEC PDP-10 Specification

- 36-bit word architecture
- 18-bit virtual address fields in classic instruction formats
- accumulator registers AC0-AC17 (18 architectural accumulators)
- instruction words organized around opcode and operand/address fields
- word-addressed memory model
- byte-pointer and byte-manipulation facilities
- arithmetic, logical, control-transfer, and I/O instructions
- processor and operating-system profile differences across the family

Exact physical address width, memory capacity, paging, and timing are profile-dependent.
