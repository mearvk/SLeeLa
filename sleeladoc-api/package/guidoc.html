guidoc #sleela 3.0 (lib/guidoc/guidoc.sleela)

GuiDoc class

The launcher of the document GUI. It builds the GUI from its spec, runs the readiness gate, optionally opens the file named by the environment variable SLEELA_GUIDOC_OPEN, prints the screen as a text outline and says whether the GUI is ready. SLEELA_GUIDOC_ADMIN=1 makes the session an admin and SLEELA_GUIDOC_LOCK=1 (admin only) locks the system before the screen is printed. With SLEELA_GUIDOC_PLAN=1 it also prints the mount plan a windowing host consumes. On a host with no display it stops there; a windowing host drives the same SLGuiDocApp through click(), type() and accelerate(). Output ends with GUIDOC READY or GUIDOC NOT READY (SLeeLa 3.0 main cannot set an exit status, so scripts match that line).

Carries the standard Metadata Class record — eleven catalogued provenance attributes (version, id, author, date, copyright, trademark, corporation, origin, birth date, science rating, national schedule) with matching get/set accessors. These are omitted from the tables below for brevity.

SLGuiDocFile #sleela 3.0 (lib/guidoc/SLGuiDocFile.sleela)

SLGuiDocFile class

Defines SLGuiDocFile — load and save for the document GUI over the openFile / read / write / close, osRename, osMakeDir and osRemove bridge. Save writes the document as plain text (lines joined by newline, with a trailing newline) through a temporary file and a rename, then writes a sidecar directory holding one file per line. Load never trusts a split: SLeeLa cannot cut a String into lines, so it reads the whole file and accepts the sidecar lines only if joining them reproduces the file EXACTLY. Otherwise the file is opened unsplit (one block) and the GUI keeps it read-only. Nothing is ever loaded that the file does not literally contain.

SLGuiDocListener class

Defines SLGuiDocListener — the GUI document listener, in white. Its nested Responder is an observer module (a drop-in, admitted through a bounded port) that listens to the standing document of one tab. Every change latches a repaint, and the listener tells changes made through the GUI apart from changes made by someone else (an external change is flagged, shown in the status line, and never silently absorbed). It speaks the white theme through SLGuiDocWhite.

SLGuiDocReady #sleela 3.0 (lib/guidoc/SLGuiDocReady.sleela)

SLGuiDocReady class

Defines SLGuiDocReady — the readiness gate and ready lifecycle of the document GUI. Like a document-ready event, the GUI is CREATED, then CHECKING while named self-checks run, then READY (every check passed) or FAILED (the first failure is kept). Nothing may act on the GUI before it is ready. Subscribers register by name with whenReady() and take a one-shot latch once the GUI is ready; a subscriber that registers late still gets its latch. A failed gate never fires a subscriber, and begin() can retry.

Carries the standard Metadata Class record — eleven catalogued provenance attributes (version, id, author, date, copyright, trademark, corporation, origin, birth date, science rating, national schedule) with matching get/set accessors. These are omitted from the tables below for brevity.
