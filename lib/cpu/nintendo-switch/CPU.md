# Nintendo Switch — CPU Reference

## Hardware Profile

| Field | Reference |
|---|---|
| System | Nintendo Switch |
| CPU/GPU | Custom NVIDIA Tegra processor |
| CPU architecture | NVIDIA Tegra X1-class ARM design |
| CPU clock | Up to ~1.785 GHz in later/current system configurations; software and mode dependent |
| System memory | 4 GB LPDDR4 |
| Internal storage | 32 GB |
| Launch | 2017 |
| Launch MSRP | $299.99 US |
