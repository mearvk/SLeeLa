# SLVM/6 Security

SLVM/6 preserves /5 fail-closed controls and adds continuous verification. Migration validates checkpoint, artifact, policy, runtime, capability, certificate, and attestation evidence. Lease authority can be revoked by epoch. Resolver provenance follows lineage. Observer evidence can be independently verified. Failure-domain isolation prevents a failed remote component from silently becoming an authority source.

Compliance profiles are technical deployment controls and do not by themselves constitute legal certification.
