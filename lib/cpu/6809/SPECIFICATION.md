# Motorola 6809 Specification

- 8-bit data architecture
- 16-bit address space
- Accumulators A and B, each 8 bits
- D register formed by A:B for 16-bit operations
- X and Y index registers
- U user stack pointer; S system stack pointer
- 16-bit program counter
- Direct page register DP
- Condition-code register CC
- Variable-length instructions and rich indexed addressing
- MC6809 and externally clocked MC6809E profiles
