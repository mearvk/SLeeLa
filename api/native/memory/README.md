# SLeeLa Memory Manager

Portable C/C++17 memory manager with tracked allocations, limits, structure insertion, named Leech attachments, validation and telemetry. The Leech is a non-owning tracked attachment to an inserted structure. It never implicitly frees its target.

The flow telemetry exposes abstract voltage/current/flow/condition values derived from memory pressure and activity. These are program-state metrics, not physical voltage/current measurements in RAM.
