hotlink-demo #sleela 3.0 (lib/hotlink/hotlink-demo.sleela)

HotLinkDemo class

Runnable, self-checking demonstrator for the hot-link backing model. It seeds the standard matrix, then drives the linker: observer modules are hot-attached, the vertical-integration stack is expanded one tier per kind (0 to 16), connections are allowed only where the matrix declares them, value moves only along approved connections, and the refusal paths (cold type, trust floor, caps, duplicate, cycle, native authorizer and pinned digest, detach) all fail closed. Prints PASS or FAIL per check and a tally.

SLHotLinker #sleela 3.0 (lib/hotlink/SLHotLinker.sleela)

SLHotLinker class

Defines SLHotLinker — the gate every hot-loaded instance and every connection passes through. It checks an instance against its matrix row (known type, hot, trust floor, per-type cap, unique name, and for native code the host authorizer plus the host-pinned digest), records it, and for observer modules admits the port to the SLDocumentObserver. A connection is allowed only if the matrix declares the type pair, fan-out stays under the limit, and no instance-level cycle results. The linker approves; it never loads code itself. Everything is audited.

Carries the standard Metadata Class record — eleven catalogued provenance attributes (version, id, author, date, copyright, trademark, corporation, origin, birth date, science rating, national schedule) with matching get/set accessors. These are omitted from the tables below for brevity.

SLHotLinkIntegration #sleela 3.0 (lib/hotlink/SLHotLinkIntegration.sleela)

SLHotLinkIntegration class

Defines SLHotLinkIntegration — the vertical-integration side of the backing model. It owns an SLVerticalIntegration and grows it only through the SLHotLinker: a tier is added by expand(), which first has the linker approve the compartment type for that kind. Value moves only where the linker says two instances are connected: deposit() puts units into a compartment from a connected module, and feed() moves units downstream between connected, adjacent tiers.

SLHotLinkMatrix #sleela 3.0 (lib/hotlink/SLHotLinkMatrix.sleela)

SLHotLinkMatrix class

Defines SLHotLinkMatrix — the backing model of the hot-link matrix: which types of class may be hot-loaded, and which types may be connected to which. Everything is validated as it is added and a bad row or link is refused (fail closed). seal() freezes the matrix; SLHotLinker only accepts a sealed one. standard() seeds the matrix declared in hotlink-matrix.xml, and tools/validate_hotlink_matrix.py checks the two agree.
