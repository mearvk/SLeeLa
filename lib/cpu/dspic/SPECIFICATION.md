# dsPIC Specification

The selected device profile defines ISA generation, program/data address model, register widths, memory map, interrupt controller, peripherals, and instruction timing. Depending on the family member, capabilities may include DSP accumulators, hardware multiply/MAC, barrel shifting, modulo or bit-reversed addressing, zero-overhead loops, flash, timers, capture/compare, serial interfaces, ADC, and DMA. Enable only capabilities documented for the selected device.
