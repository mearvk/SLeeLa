# HTML Tags (1991) — the first HTML document

`Tags.html` in this directory is the original **"HTML Tags"** note — the earliest surviving
description of HTML, written by Tim Berners-Lee at CERN. It is the document that
[`../../markdown/01-html-tags-1991.md`](../../markdown/01-html-tags-1991.md) writes up, and it is the
source referenced by the main [README](../../README.md) as *"❌ (unobtainable)"* — that gap is
now **closed**.

## What this is

A plain listing of the ~20 tags that made up the first version of HTML: `<TITLE>`, `<NEXTID>`,
`<A>` (anchors, with `NAME`/`HREF`), `<H1>`–`<H6>`, `<P>`, address, the quoting/literal tags
(`<XMP>`, `<LISTING>`, `<PLAINTEXT>`), the highlighting tags (`<HP1>`/`<HP2>`), glossary/definition
lists (`<DL>`/`<DT>`/`<DD>`), and the list tags (`<UL>`, `<MENU>`, `<DIR>` with `<LI>`). It is
written *in* the markup it describes and still carries the period details — the `<NEXTID 22>`
document-wide identifier, the `info.cern.ch` anchor URLs, and notes such as "NOT CURRENTLY USED".

This is **not** a formal specification with a grammar — HTML in 1991 had no DTD. It is the
informal reference that predates HTML 2.0 (RFC 1866, 1995) by four years.
