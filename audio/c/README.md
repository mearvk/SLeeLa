# SLeeLa Audio C

C11 duplicate of the native audio contract. It preserves the same C ABI, validation rules, PCM16 WAV boundary, synchronized offsets, gain, master gain, pan, and stereo WAV output as the C++ implementation.

Build: `make clean all test`.
