## Suggested placements
| Item | Placement | Method |
|---|---|---|
| Hoodie | 80–100 mm left chest; optional back mark | Screen print / embroidery |
| T-shirt | 70–90 mm centered chest | Screen print / DTG |
| Cap | 35–45 mm front mark | Embroidery |
| Mug | 55–70 mm mark on each side | Ceramic transfer |
| Tumbler | 25–35 mm vertical mark | Laser engraving / UV print |
| Tote | 100–130 mm centered mark | Screen print |
| Notebook | 30–45 mm cover mark | Foil / emboss / print |
| Stickers | Full-color and single-color cutline | Vinyl |

## Pre-production checklist
- [ ] Confirm legal ownership and permissions for assets and slogan.
- [ ] Confirm vendor color profile, bleed, safe area, and minimum line thickness.
- [ ] Proof at final size on the actual material.
- [ ] Approve a physical sample before bulk production.
- [ ] Add supplier, SKU, price, and order URL only after procurement is real.
