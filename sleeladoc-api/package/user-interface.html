GuiAppDemo class

Runnable demonstrator for the /lib/gui support structure. It boots an SLGuiApp (application + window + DOM + reconciler + host adapter + script engine), builds a small interface in the SLeeLa DOM, binds an onClick callback, drives part of the UI from a script, refreshes once to project the DOM onto real SleelaUI widgets, and (on a display) hands control to the run loop. SLBox (lib/user-interface/SLBox.sleela)

SLBox class extends SLWidget

SLWindow (lib/user-interface/SLWindow.sleela)

SLWindow class

Defines SLWindow — a top-level SleelaUI window opened from SLeeLa source. It wraps the toolkit's window built-ins: uiWindowCreate (bound to an application + theme), uiWindowShow/Hide, uiWindowSetTitle, uiWindowRoot (the root container to add widgets to), uiWindowSetTheme, and uiWindowRedraw. Underneath, the VM calls the SleelaUI C ABI, which creates a real native window (X11/Cocoa/Win32) and paints it with the toolkit's own software rasterizer, so the window looks identical on every platform. Lifecycle: configureOn(app, title, w, h, theme) is called by SLUserInterface; then show(), set the title, add widgets to root(), and the application's run loop drives it. A window is a VM-local handle (-1 = none). Family: user-interface. Native VM/UI work crosses the explicit `ui*` SLVM bridge.

Carries the standard Metadata Class record — eleven catalogued provenance attributes (version, id, author, date, copyright, trademark, corporation, origin, birth date, science rating, national schedule) with matching get/set accessors. These are omitted from the tables below for brevity.
