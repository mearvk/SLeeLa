# Motorola 68040 CPU

SLeeLa models the MC68040 as the major superscalar 68000-family transition: an integrated integer/FPU processor with on-chip instruction and data caches and integrated memory-management hardware.

The 68040 is kept distinct from the 68030 and 68060 rather than collapsing all later 68K behavior into one model.

## Profiles

- MC68040
- MC68LC040 — FPU removed
- MC68EC040 — MMU/FPU configuration differences

The profile controls optional execution and memory-management resources.
