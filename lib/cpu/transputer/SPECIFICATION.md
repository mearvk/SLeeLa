# Inmos Transputer Specification

## Programmer state

Transputer implementations provide:

- workspace/register state for process execution;
- instruction pointer;
- operand evaluation state;
- processor status/control state;
- scheduler/process state.

## Architectural facilities

- integer arithmetic and logic;
- expression-oriented instructions;
- procedure calls;
- hardware-supported process scheduling;
- channel communication;
- serial communication links;
- timer facilities;
- optional floating-point unit on applicable members.

The transputer's communication and process model is a primary architectural feature.
