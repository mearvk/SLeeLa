# HTTP 6.0 Flow

1. Establish an authenticated carrier.
2. Negotiate HTTP 6.0 capability.
3. Open a logical stream/request.
4. Import or construct HTTP 5.0 Friends' Pack data.
5. Add consolidated pack metadata.
6. Add optional debate fields.
7. Serialize the pack as ordinary application content.
8. Frame it using the HTTP 6.0 frame format.
9. Send only to an explicitly selected recipient/resource through an authorized channel.
10. The receiver validates the frame and application content.
11. The receiver may accept, reject, ignore, or filter the pack.
12. AUDIT records conformance events without altering network behavior.

The debate option is a structured communication format, not an instruction to pressure, threaten, attack, or interfere with a recipient.
