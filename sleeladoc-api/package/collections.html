SLArray #sleela 2.5 (lib/collections/SLArray.sleela)

SLArray class

A concrete, fixed-capacity, bounds-safe String array wrapper built directly on the VM-managed native array primitive. Unlike SLList, the logical length equals the capacity: every slot is addressable from construction and defaults to null. This first implementation deliberately avoids Generics and mirrors the storage discipline of SLList.

Carries the standard Metadata Class record — eleven catalogued provenance attributes (version, id, author, date, copyright, trademark, corporation, origin, birth date, science rating, national schedule) with matching get/set accessors. These are omitted from the tables below for brevity.

SLQueue #sleela 2.5 (lib/collections/SLQueue.sleela)

A concrete, String-valued FIFO queue backed by the VM-managed growable native array. enqueue appends to the tail; dequeue removes from the head. A head cursor avoids shifting on every dequeue; storage is compacted when the dead prefix dominates. Deliberately avoids Generics.
