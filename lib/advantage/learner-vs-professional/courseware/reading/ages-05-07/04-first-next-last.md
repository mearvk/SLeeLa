# First, Next, Last

Some jobs need an **order**.

To make toast:

1. **First:** put the bread in the toaster.
2. **Next:** push the lever down.
3. **Then:** wait.
4. **Last:** take the toast out.

What if you take the toast out first? There is no toast yet!

Steps have numbers: 1, 2, 3, 4. A helper only takes the **next** number. If you
say step 3 when you did step 1, the helper says: "That does not come next."

**Try it:** Build a block tower and say "First... Next... Last...". Count the steps.
