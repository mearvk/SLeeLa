Security2 #sleela 3.0 (lib/security/Security2.sleela)

Security2 class

Security2 sits above the VM in colocated memory. It is placed when the VM boots and follows the VM through init and start. Until the VM has fully initialized, the Sleela.home lineage references (parent, child, parents) point to Security2 instead of the VM (SLEELA.syntax section 42.6). Phases are small integers: 0 = off, 1 = booting, 2 = initializing, 3 = started, 4 = ready (fully initialized).

Carries the standard Metadata Class record — eleven catalogued provenance attributes (version, id, author, date, copyright, trademark, corporation, origin, birth date, science rating, national schedule) with matching get/set accessors. These are omitted from the tables below for brevity.
