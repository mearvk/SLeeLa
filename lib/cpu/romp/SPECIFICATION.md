# IBM ROMP Specification

## Programmer state

- 32-bit general-purpose registers
- program counter
- condition/control state
- privileged/system state

ROMP uses a fixed-width RISC instruction model with register-oriented arithmetic, memory operations, branches, and procedure support.

## System facilities

Depending on implementation/platform:

- instruction/data memory hierarchy;
- virtual-memory support;
- protection;
- interrupts/exceptions;
- system-bus and DMA facilities.
