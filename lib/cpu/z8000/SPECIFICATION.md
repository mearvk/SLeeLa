# Zilog Z8000 Specification

- 16-bit processor family
- Z8001 segmented-address and Z8002 non-segmented profiles
- 16 general-purpose registers, with byte/word and register-pair use as defined by the profile
- variable-length instruction encoding
- register, immediate, and memory operands
- condition-code and control state
- interrupt and system-control support
- profile-dependent address width, MMU, cache, and bus details

Z8001 and Z8002 are distinct profiles; do not apply the Z8001 segmented address model to the Z8002.
