# C++ Integration Example

C++ is the primary native implementation integration example.

The host IDE/tooling remains authoritative for C++ syntax and semantics. SLeeLa integration recognizes C++ source and headers, exposes SLeeLa-to-native navigation and connects native debugging to the SLeeLa source map.

The SLeeLa foundational C++ classes under impl/fundamental are part of this integration surface.
