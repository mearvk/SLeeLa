Linux native coverage

Slecompiler™ models ELF executables, shared objects including versioned .so.* libraries, relocatable .o objects, GNU archives .a, and Linux kernel modules .ko. Dynamic-library relationships and kernel-module metadata remain static evidence and retain provenance.

Design

Input artifacts are never executed or modified. Generated C/C++ is a separate refactoring product and carries provenance back to the analyzed artifact.
