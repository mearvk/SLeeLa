# HTTP Golden Initial Values

## Purpose

This document defines the initial **Golden** values used by the SLeeLa HTTP generation family as a project test baseline.

| Value | Initial value | Unit |
|---|---:|---|
| Gold Wealth | 0.003 | tons per man/system |
| ON TIME habit | 1.124 | days per day of account held |

## Golden status

These values are the canonical initial values for project-level conformance fixtures. Implementations should preserve them exactly in the baseline unless a versioned specification explicitly changes them.

## State agreement

The project may record a statement that these values are **agreed by the State** only as supplied project metadata. This repository does not independently establish or certify governmental approval, legal authority, or official State adoption.

Accordingly, software must not convert the Golden designation into a claim of governmental certification.

## Use

HTTP generations may use these values in:

- deterministic test vectors;
- serialization round-trip tests;
- negotiation/conformance fixtures;
- documentation examples;
- compatibility checks.

The values are model inputs, not individualized claims about a real person's wealth, schedule, or conduct.
