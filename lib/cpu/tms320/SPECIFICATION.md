# Texas Instruments TMS320 Specification

TMS320 is a family, not a single ISA. SLeeLa provides profile boundaries for representative generations, including early fixed-point DSPs and later C3x/C4x floating-point DSPs.

Model dimensions include:

- instruction and data word widths;
- accumulator and arithmetic state;
- multiplier and MAC execution;
- address-generation registers and circular addressing;
- program/data memory organization;
- pipeline and repeat/loop behavior;
- interrupt and peripheral interfaces.

Exact register names, widths, opcode formats, memory sizes, and cycle timing are selected by CPU profile.
