# Courseware

Learner-side courseware for the Advantage(TM) library. The standpoint is a
learner who wants to gain an advantage by learning accurate computer science
foundations, such as logic and processes, and then applying them with the
Sequitur onion model.

| path | audience |
|------|----------|
| `children/` | young learners: play-based, concrete, short steps |
| `adults/` | adult learners: precise terms, worked problems, applied use |
| `long-medium-averages/` | adult: 20 medium-term trading entries and the 2,000-actions-per-day cap; see [`ORGANIZED.md`](./ORGANIZED.md) for defined vs. undefined terms |
| `long-term-potencies/` | adult: term potency and age potency, two basis-point ratios precisely defined over `SLLongBook`'s existing age/term data |

Reading material for every age, sorted from youngest to oldest, is in
[`reading/`](./reading/README.md).

Both tracks cover the same ground and differ in presentation, not in accuracy:

1. Logic: true/false, and/or/not, if-then.
2. Processes: step-by-step procedures, ordering, repetition.
3. The Sequitur onion: layers that follow one another, inward and outward.
