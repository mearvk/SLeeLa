- new Counter/Ledger create objects on the Java 28 heap; Sleela receives only
  handles (h:1, h:2).

- ledger.cents() returns ANOTHER heap object, exposed as a fresh handle (h:3);
  its value is 2500 (balance 25.00 -> 2500 cents).
- Security posture: a non-allow-listed class (File) and a released handle both
  return ERR, never an escape hatch. stats shows the bounded live-handle model.
