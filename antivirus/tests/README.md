# Sleelavirin™ Tests

Tests should cover:

- known-benign inputs;
- known detection metadata represented without distributing harmful samples;
- malformed files and metadata;
- oversized inputs;
- scanner unavailable/error conditions;
- digest mismatches;
- provenance mismatches;
- policy decisions;
- platform adapter behavior.
