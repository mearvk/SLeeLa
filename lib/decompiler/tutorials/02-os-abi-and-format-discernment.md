# Tutorial 02 — OS, ABI, and Format Discernment

Combine format headers, ABI markers, imports/exports, relocation data, calling conventions, section names, runtime metadata, architecture instructions, symbols/debug data, and producer/compiler fingerprints.

Evidence should be weighted and conflicts preserved. A single magic number is initial evidence, not proof of the complete environment. Seek agreement among architecture, object format, ABI, and OS evidence before assigning a strong platform conclusion.

Inspect OSDiscernment.sleela, LanguageReference.sleela, BinaryFormatReference.sleela, and SafetyReference.sleela.
