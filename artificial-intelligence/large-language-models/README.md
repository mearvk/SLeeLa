# Large Language Models

This directory contains SLeeLa large-language-model integrations, inference interfaces, examples, and supporting documentation.

## Planned areas

- Model-provider and local-model adapters
- Tokenization and vocabulary utilities
- Prompt construction and conversation context
- Text generation and decoding strategies
- Streaming and tool/function calling
- Retrieval-augmented generation
- Evaluation, safety, and usage controls

Keep provider-specific integrations isolated behind consistent interfaces. Document model requirements, licensing, configuration, network access, resource use, and supported platforms. Never embed credentials or assume an external service is configured. Provide local/offline options where practical.
