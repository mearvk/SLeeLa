# MIT TX-0 CPU

SLeeLa profile for the MIT Lincoln Laboratory TX-0, an experimental transistorized computer developed in the 1950s.

- **Status:** profile-driven functional foundation; not a cycle-accurate reproduction.
- **Word model:** 18-bit words.
- **Design:** experimental stored-program computer with accumulator/register state and memory/control operations.
- **Configuration:** memory size, instruction interpretation, console devices, and timing are machine-profile settings.
- **Scope:** model the TX-0 as its own machine, not as a PDP-family variant.

Historical implementations and configurations can differ. Unconfirmed opcode details and timing are explicitly left unspecified rather than guessed.
