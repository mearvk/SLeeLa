# Nintendo Wii U — CPU Reference

## Hardware Profile

| Field | Reference |
|---|---|
| System | Wii U |
| CPU | IBM Espresso, PowerPC-derived, 3-core |
| CPU clock | ~1.24 GHz |
| Main RAM | 2 GB DDR3 |
| System-reserved RAM | Part of the 2 GB is reserved for system use |
| Launch | 2012 |
| Launch MSRP | $299.99 US for Basic Set |

## SLeeLa Representation

The Wii U profile models the three-core Espresso CPU and DDR3 memory environment as a multicore console CPU target.

## Compatibility Intent

The profile can be combined with SLeeLa scheduling, memory, device, and guest-machine components for architecture research.
