# Nintendo Wii — CPU Reference

## Hardware Profile

| Field | Reference |
|---|---|
| System | Nintendo Wii |
| CPU | IBM Broadway, PowerPC-derived |
| CPU clock | 729 MHz |
| Main/system memory | 88 MB total: 24 MB 1T-SRAM + 64 MB GDDR3 |
| Launch | 2006 |
| Launch MSRP | $249.99 US |

## SLeeLa Representation

The Wii profile models the Broadway PowerPC-derived CPU, its unified console memory resources, and the timing/IO characteristics needed for a Wii-class machine.

## Compatibility Intent

The profile is intended for historical CPU architecture, memory, bus, and emulator research. It does not reproduce proprietary Nintendo firmware.

## Cost Note

The price is the historical US launch MSRP.
