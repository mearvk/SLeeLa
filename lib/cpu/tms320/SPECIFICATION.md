# Texas Instruments TMS320 Specification

TMS320 is a family, not a single ISA. SLeeLa provides profiles for representative generations, including early fixed-point DSPs and later C3x/C4x floating-point DSPs. Model dimensions include instruction/data widths, accumulator and arithmetic state, multiplier/MAC execution, address-generation registers, circular addressing, program/data memory organization, pipeline and repeat/loop behavior, interrupts, and peripherals. Exact register maps, opcode formats, memory sizes, and cycle timing are profile-specific.
