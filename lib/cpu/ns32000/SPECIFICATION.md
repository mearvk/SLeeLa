# NS32000 Specification

## Programmer state

- 8 general-purpose 32-bit registers
- 32-bit program counter
- processor status/control state
- stack and frame-oriented procedure support

The architecture uses variable-length instructions and a broad set of operand addressing forms.

## Facilities

- integer arithmetic and logical execution
- multiply/divide
- bit operations
- procedure call/return
- memory operations
- floating-point coprocessor support where provided
- memory-management support in applicable members
- interrupts and exceptions
