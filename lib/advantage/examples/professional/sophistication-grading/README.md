# sophistication-grading

The `grading/` subject: scoring and ranking professional work.

- `grading-primer.sleela` — the scoring modules and the ranking of winning /
  losing / grader / absolute sets A–D. Links the sibling classes in
  `lib/advantage/grading/` (`SLModuleGrade`, `SLGradeSet`,
  `SLSophisticationCircuit`, `SLGradeBook`).
- `professionals-demo.sleela` — scores a cohort of six professional roles and
  ranks the winners A–D.

```sh
./working-binaries/sleela run lib/advantage/examples/professional/sophistication-grading/professionals-demo.sleela
```
