HTML 2.0 (RFC 1866, 1995) — Use-Case Demonstration

Date: 2026-10-25

This document demonstrates the elements standardized by HTML 2.0 (the first formal HTML specification) in their usual use cases. Each example states whether it still performs as expected in a modern browser: ✓ Yes, or ✗ No.

Title: html / head / body structure  |  Date: 2026-10-25

Performs as expected: ✓ Yes

Use case 9 — Searchable-document prompt

Title: Keyword search prompt  |  Date: 2026-10-25

<isindex> marked the document as searchable. (Not emitted live — no longer renders a prompt.)

Performs as expected: ✗ No — obsolete; use a <form> with an <input>.

Summary: HTML 2.0's structural, text, list, image and form elements all still perform as expected today. Only <isindex> (and the now-obsolete <tt>) fall short of modern expectations.
