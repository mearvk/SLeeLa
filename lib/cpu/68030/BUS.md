# Motorola 68030 Bus

The 68030 retains the 32-bit address/data system interface of the 68020 family and adds burst-oriented memory transfers. NXP explicitly identifies its bursting data bus as a major 68020 upgrade. citeturn0search0

Transactions include:

- address;
- function code;
- read/write;
- size;
- data;
- byte enables;
- burst state;
- acknowledge;
- bus error;
- retry/arbitration state.

DMA remains external/system-level.
