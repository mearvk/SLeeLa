Communication (lib/telephony-skya/Communication.sleela)

Communication class

Defines Communication, the Skya message-exchange Master Class — client-side reach / send / receive with an honest coherence tally. Communication is an emblematic Skya module and a NATURAL / LOADABLE MODULE sharing the common module contract (load / loaded / moduleName / describe). Where Servers stands ready and Network describes reach, Communication performs the client-side exchange and keeps a simple, honest tally of what was sent and received so a program can tell whether a conversation actually completed. It uses the same portable VM socket primitives as SkyaClient (connect / sockwrite / sockread / sockclose) across the explicit SLeeLa VM/OS bridge. The runnable orchestration example lives in telephony-skya/sleela/Communication.sleela. Family: telephony-skya. Native VM/OS work crosses an explicit bridge.

Network class

RealAcquaintances (lib/telephony-skya/RealAcquaintances.sleela)

RealAcquaintances class

Defines RealAcquaintances, the Skya trust-roster Master Class — the people a node has actually met and confirmed. RealAcquaintances is an emblematic Skya module and a NATURAL / LOADABLE MODULE sharing the common module contract (load / loaded / moduleName / describe). It is the counterpart to Socio: Socio models the social fabric in the abstract; RealAcquaintances records concrete, confirmed acquaintances a node will preferentially reach and admit. An acquaintance becomes "real" only after a confirmed two-way exchange, so the roster never contains unverified entries. It holds roster state only; the confirming exchange is performed by the Communication module. The runnable orchestration example lives in telephony-skya/sleela/RealAcquaintances.sleela. Family: telephony-skya. Native VM/OS work crosses an explicit bridge.
