# Xbox CPU Model Reference

All Xbox CPU models use direct, lowercase directory names under `/lib/cpu`.

| Model | CPU | Speed | Main RAM | US Launch MSRP |
|---|---|---:|---:|---:|
| `xbox` | Intel Pentium III-derived | 733 MHz | 64 MB | $299 |
| `xbox-360` | IBM Xenon, 3-core PowerPC | 3.2 GHz | 512 MB | $299 / $399 |
| `xbox-one` | AMD Jaguar, 8-core | 1.75 GHz | 8 GB | $499 |
| `xbox-one-s` | AMD Jaguar, 8-core | 1.75 GHz | 8 GB | $299 |
| `xbox-one-x` | AMD Jaguar-derived, 8-core | 2.3 GHz | 12 GB | $499 |
| `xbox-series-s` | AMD Zen 2, 8-core | 3.6 GHz | 10 GB | $299 |
| `xbox-series-x` | AMD Zen 2, 8-core | 3.8 GHz | 16 GB | $499 |

These are historical hardware reference profiles for SLeeLa CPU and machine modeling. They do not contain proprietary firmware or software.
