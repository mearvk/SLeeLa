# IDE Debugger Integration

The SLeeLa IDE debugger adapter connects IntelliJ debugger actions to the repository's /debugger implementation.

Required mapping: continue, pause, step over, step into, step out, run to cursor, breakpoints, exception points, watchpoints, stack frames, locals, source locations, thread selection, termination and diagnostics.

The adapter should preserve the existing line-control and voice-control model rather than creating a competing debugger vocabulary.
