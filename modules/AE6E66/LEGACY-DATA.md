# AE6E66 Legacy Data Notice

The checked-in `contacts.csv` contains historical records retained for continuity. Records marked `legacy-unverified` lack sufficient current provenance and must not be treated as current operational contact records. Records marked `legacy-public` are historical public-source records whose present accuracy still requires revalidation.

Before operational use, replace or revalidate legacy records using authoritative current sources and populate `source` and `retrieved_at` fields. Do not infer missing contact information from historical values.
