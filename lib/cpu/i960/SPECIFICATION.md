# Intel i960 Specification

## Programmer state

- 32-bit general-purpose registers
- instruction pointer
- arithmetic/control condition state
- procedure/register-cache state
- profile-specific control and protection registers

## Execution

The i960 uses a RISC-oriented fixed-format instruction architecture with register-based arithmetic, memory operations, branches, and procedure support.

Later members add stronger cache, memory-management, floating-point, and protection facilities.
