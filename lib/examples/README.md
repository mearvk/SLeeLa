# SLeeLa Library Examples

This directory contains example programs and reference implementations that demonstrate how to use the SLeeLa library (`/lib`).

## Organization

- Keep examples grouped by the library subsystem or API they demonstrate.
- Prefer small, focused examples that can be built or run independently.
- Include any required build/run instructions and dependencies alongside each example group.
- Keep reusable library implementation code in its existing subsystem directory; place demonstration and sample code here.

## Adding examples

Create a clearly named subdirectory for a subsystem or feature, include the example source files, and document how to build and run them.
