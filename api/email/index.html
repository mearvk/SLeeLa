SLeeLa Email Facade API

SMTP-aware native C API with TLS-aware transport and a SLeeLa mapping.

Functions

  • sleela_email_send
  • sleela_email_tls_mode_name

Transport

STARTTLS upgrades SMTP to TLS. IMPLICIT starts TLS before SMTP. NONE is unencrypted.

Identity

smtp_host accepts a DNS name or IP. local_bind_host can select a local source address. helo_name is sent in EHLO.
