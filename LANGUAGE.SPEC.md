# SLeeLa Language Specification

Engineering contract for version resolution, lexical/syntactic parsing, semantic analysis, typing, lowering, diagnostics and compatibility. A compiler must reject unsupported language versions before normal compilation and must distinguish lexical, syntax, semantic, version, lowering and runtime failures.

The surface language ABI, core ABI and native ABI are versioned independently. Conformance requires positive, negative, version and platform tests.

Normative companions: `src/Sleela.manifest`, `src/Sleela.formal-core`, `SLEELA.syntax`.
