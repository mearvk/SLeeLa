BusinessModel #sleela 2.5 (lib/character/BusinessModel.sleela)

BusinessModel class

Defines BusinessModel, the language-neutral base contract a developer extends to describe how a Character actually makes a living. It is the heart of the character package's business-model family: every concrete model (subscription, freemium, marketplace, advertising, retail, wholesale, franchise, licensing, SaaS, consulting, manufacturing, brokerage) subclasses it and overrides the revenue math. A new model is created exactly like a compiler front end in lib/compiler: subclass BusinessModel, call configure() to declare identity, and override monthlyRevenue()/monthlyCost() with the model's own economics. The base implementations are deliberate no-ops that report "nothing yet", so an un-overridden model is honest rather than magical. BusinessModel is a NATURAL / LOADABLE MODULE sharing the common module contract (load / loaded / moduleName / describe). It holds model state only; a Character owns one and asks it, each month, "so — did we make money?". Family: character. Settlement crosses an explicit bridge to the ledger.

Carries the standard Metadata Class record — eleven catalogued provenance attributes (version, id, author, date, copyright, trademark, corporation, origin, birth date, science rating, national schedule) with matching get/set accessors. These are omitted from the tables below for brevity.

CharacterDemo class

Casts three Characters, hands each a different BusinessModel, and runs a quarter of business.
