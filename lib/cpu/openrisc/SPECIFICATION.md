# OpenRISC 1000 Specification

A selected profile identifies the ORBIS instruction-set revision, operand/address widths, endianness, privilege model, exception vectors, SPR inventory, optional extensions, and system integration. Optional features such as floating point, DSP, atomic operations, debug, MMU, and caches must be enabled only where the selected implementation documents them. Exact opcode behavior and reserved encodings follow the selected ISA revision.
