# SleelaTerminal™ — product identity

**SleelaTerminal™** is SLeeLa's terminal **product**. It is **built on GNU Bash**
(free software, GPL, © Free Software Foundation). This document describes the
SleelaTerminal™ product identity — the branding for the executable's banner, the
GUI title, the About dialog, and the installer/package name — and the license
boundary that keeps it honest.

> **The boundary, up front.** SleelaTerminal™ branding applies **only** to the
> SLeeLa-authored components (the Phraign™ pixel-terminal layer, `model-3D/`, and
> the product-identity files here). The vendored **GNU Bash** engine keeps its
> own version string, startup banner, copyright, `AUTHORS`, and `COPYING`
> **unchanged**. SleelaTerminal™ does not claim authorship of GNU Bash. See
> [`NOTICE`](NOTICE).

## What SleelaTerminal™ is

A branded product with two layers:

| Layer | What it is | Identity |
|---|---|---|
| **Product** | The SLeeLa-authored terminal — Phraign™ frame control, `model-3D/`, product surfaces | **SleelaTerminal™** (ours) |
| **Engine** | The shell that executes commands | **GNU Bash** (free software, GPL, © FSF) |

A product may be branded SleelaTerminal™ while its underlying shell engine
remains, and is acknowledged as, GNU Bash. That is the standard way to ship a
branded product built on free software: **brand what you authored; attribute
what you incorporated.**

## Product identity files

| File | Role |
|---|---|
| [`sleelaterminal.h`](sleelaterminal.h) | Version/identity constants for the SLeeLa product layer (name, version, GUI title, package, and honest engine-credit macros). |
| [`sleelaterminal.sh`](sleelaterminal.sh) | Helpers that print the product banner / version / GUI title / installer name / About text. |
| [`NOTICE`](NOTICE) | Product attribution: SLeeLa's authorship of the product + GNU Bash engine credit. |
| [`SLEELATERMINAL.md`](SLEELATERMINAL.md) | This document. |

The SleelaTerminal™ product version is **`1.0.0`** (independent of the GNU Bash
engine version, which comes from Bash itself).

## Branding the product surfaces

All product text is generated by [`sleelaterminal.sh`](sleelaterminal.sh), which
always prints the SleelaTerminal™ product line **alongside** — never instead of
— GNU Bash's own version, and queries Bash's real `--version` rather than
fabricating one.

```sh
# from bash/
./sleelaterminal.sh banner       # startup banner (product line + real engine version)
./sleelaterminal.sh version      # SleelaTerminal(TM) 1.0.0
./sleelaterminal.sh engine       # the real GNU Bash version, from Bash
./sleelaterminal.sh gui-title    # window / title-bar string
./sleelaterminal.sh package      # installer / package name
./sleelaterminal.sh about        # About dialog text
```

### Startup banner

```text
SleelaTerminal(TM) 1.0.0
  powered by GNU bash, version <the real Bash version>
```

### GUI title

The window title / title-bar string is **`SleelaTerminal(TM)`**
(`SLEELATERMINAL_GUI_TITLE`). A GUI host uses this for its window title while the
running shell is still GNU Bash.

### Installer / package name

The installable product is packaged as **`sleelaterminal`**
(`SLEELATERMINAL_PACKAGE`). The package *contains* GNU Bash and credits it in the
About text and `NOTICE`; it does not rename or re-license the Bash binary.

### About dialog

```text
SleelaTerminal(TM) 1.0.0
A SLeeLa product.

Powered by GNU Bash
  GNU bash, version <the real Bash version>
  GNU General Public License (GPL)
  Copyright (C) Free Software Foundation, Inc.

GNU Bash is free software. The GNU Bash engine retains its own license
and copyright; see the NOTICE file. SleelaTerminal(TM) branding
applies to the SLeeLa-authored product layers only.
```

## What is deliberately NOT changed

To stay within the GPL, SleelaTerminal™ never edits the vendored Bash tree's:

- version string or `--version` output,
- startup/interactive banner,
- copyright notices, `AUTHORS`, or `COPYING`,
- references to GNU projects.

Those belong to the Free Software Foundation and the Bash contributors and are
kept intact. The product identity here lives entirely in **new, SLeeLa-authored
files** that sit on top of the pristine engine.

## Relationship to Phraign™

Inside SleelaTerminal™, **Phraign™** ([`PHRAIGN.md`](PHRAIGN.md)) is the
frame-based, pixel-accurate terminal control system, and **Phraign™ City 3D**
([`model-3D/README.md`](model-3D/README.md)) is the flagship application. This
document adds the outer product identity — the name, version, and branded
surfaces — that wraps the whole SleelaTerminal™ product.
