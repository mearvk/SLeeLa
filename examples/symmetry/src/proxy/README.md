# Proxy Server Example

A SLeeLa symmetry example for a forward proxy with explicit Client, Server, and Admin/Monitor roles.

The model keeps request forwarding, upstream selection, connection accounting, and administrative observation separate. It is a protocol-level example rather than a production proxy implementation.
