# SLVM/7 Windows Build

Windows 10+ is supported through the portable C toolchain boundary. Use MinGW/MSYS2 with the parent Makefile, or compile src/slvm7.c with MSVC using include/ on the include path. Native Windows resources are recreated through the capability boundary during migration.
