# SLeeLa Repository SHA-256 Digests

This file is generated by the repository workflow from the Git-tracked files in the active branch.

- Algorithm: SHA-256
- Scope: every Git-tracked file except this digest document itself.
- Ordering: lexicographic by repository-relative path.
- The digest document is excluded because including its own digest would create a self-referential file-content cycle.

The first workflow run will replace this bootstrap text with the complete digest inventory.
