# lib/gui/version-military — visual preview

`gui-military-preview.png` previews
[`gui-military-demo.sleela`](../gui-military-demo.sleela), the 5.0 military line:
the neutral **metal-blue** aesthetic with a **3D-lit base frame** (bevel +
key-light) and **careful quality shadows**, strong "SLeeLa Command" branding,
icon-bearing buttons/menu items, the explicit **Container/Component** taxonomy,
the **Cryptography Selector** (PQC top-secret suite, legacy gated out), and the
**Public Key Certificate Store** (trusted CA + revoked leaf → selection cleared).

> **Rendered with Chrome, from the SLeeLa descriptors — NOT the live SLeeLa
> toolkit.** `gui-military-preview.html` is a hand-authored HTML/CSS mock
> mirroring the military settings/component states the `.sleela` model produces;
> `gui-military-preview.png` is that HTML screenshotted headlessly by Chromium.
> The sandbox has no display server / no prebuilt `sleela` runtime / ABI-only
> native bridge, so the live toolkit could not render here. The preview shows
> design intent; production pixels come from the host renderer.
