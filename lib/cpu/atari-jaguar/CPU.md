# Atari Jaguar — CPU Reference

| Field | Reference |
|---|---|
| Main CPU | Motorola 68000 |
| CPU type | 16/32-bit CISC |
| CPU clock | 13.295 MHz |
| Main RAM | 2 MB |
| Launch | 1993 |
| Launch MSRP | $249.99 US |

The Jaguar also contains custom GPU/DSP processors. This CPU descriptor identifies the 68000 as the main host CPU while allowing the SLeeLa model to represent the custom processors separately.
