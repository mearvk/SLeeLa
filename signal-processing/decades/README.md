# Historical timeline index — 1951 to present

The folders in this directory offer a modest, decade-by-decade reading guide.
The boundaries are organizational: discoveries, papers, commercial products,
and adoption frequently cross decade labels, and foundational mathematics may
predate the first broadly practical digital implementations.

| Folder | Themes covered in its note |
| --- | --- |
| 1951-1959/ | Statistical estimation, noise reduction, sampled-data foundations |
| 1960s/ | Digital spectrum analysis and the Cooley–Tukey FFT milestone |
| 1970s/ | Digital audio, convolution and filter techniques |
| 1980s/ | Dedicated DSP, real-time constraints and embedded algorithms |
| 1990s/ | Wavelets, filter banks, subband coding and digital media |
| 2000s/ | Software-defined radio, distributed sensors and sparse methods |
| 2010s/ | Mobile sensing and learning-assisted interpretation |
| 2020s-present/ | Edge computation, energy/latency budgets and reproducibility |

These notes are historical context, not an exhaustive scholarly chronology.
They distinguish representative themes from capabilities actually implemented
in this codebase. Consult the source references listed in the top-level
signal-processing README before using historical claims in formal writing.
