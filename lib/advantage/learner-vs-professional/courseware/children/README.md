# Courseware: Children

Play-based lessons on logic and processes, built around the onion idea:
peel one layer at a time, and each layer follows the one before it.

Units (all five are written, each with exercises and an answer key):

1. True or false: yes/no questions and simple rules. **Written:** [unit-01-true-or-false.md](./unit-01-true-or-false.md)
2. And, or, not: combining two facts. **Written:** [unit-02-and-or-not.md](./unit-02-and-or-not.md)
3. If this, then that: following rules. **Written:** [unit-03-if-then.md](./unit-03-if-then.md)
4. Steps in order: making a recipe, then repeating steps. **Written:** [unit-04-steps-in-order.md](./unit-04-steps-in-order.md)
5. Peeling the onion: walking through layers inward and back out. **Written:** [unit-05-peeling-the-onion.md](./unit-05-peeling-the-onion.md)

Guidelines: short steps, concrete examples, no jargon without a plain-words
explanation, and every statement must be factually correct.
