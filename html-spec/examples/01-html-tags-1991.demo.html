Date: 2026-10-25

This document demonstrates the ~20 elements described in the original 1991 CERN “HTML Tags” note, each in its usual use case. Each example states whether it still performs as expected in a modern browser: ✓ Yes, or ✗ No.

    Performs as expected: ✗ No — <xmp> is obsolete; use <pre> with escaped <code>.

    Use case 12 — Searchable-document prompt

    Title: A keyword search prompt  |  Date: 2026-10-25

    <isindex> declared a document as searchable. (Not emitted live here because it no longer renders a prompt.)

    Performs as expected: ✗ No — <isindex> is obsolete; use an <input> in a <form>.

    Summary: The structural elements (title, headings, paragraphs, links, lists, definition lists, address) still perform as expected. The 1991-specific legacy tags (named <a>, old <menu>, <dir>, <xmp>, <isindex>) do not.
