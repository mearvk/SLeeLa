# Virtual machine commands

```sh
sleela vm list
sleela vm select native
sleela vm info native
sleela vm select 1
sleela vm info 1
```

The manual also documents premium selectors and VM execution forms:

```sh
sleela vm select premium 1
sleela vm info premium 1
sleela vm run native path/to/program.sleela
```

Use only selections actually listed by the installed build. VM generations and
premium availability are build/configuration dependent.
