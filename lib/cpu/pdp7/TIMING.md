# PDP-7 Timing

No cycle-accurate timing is claimed by the baseline profile.

- **Functional mode:** deterministic instruction semantics.
- **Timed mode:** requires explicit PDP-7 timing metadata for each supported operation and any relevant I/O interaction.
- **Missing timing:** report unavailable; do not copy PDP-4 or PDP-9 timing figures.

Timing entries should record provenance and distinguish documented values from estimates. Host wall-clock runtime must not be presented as guest instruction timing.
