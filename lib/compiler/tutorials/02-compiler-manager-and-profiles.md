# Tutorial 02 — Compiler Manager and Profiles

BASIC_COMPLETE provides a complete practical compiler path. ADVANCED_TOTAL adds explicit inventory of semantic requirements, capabilities, dependencies, security constraints, provenance, target architecture, VM fitment, and output requirements.

Flow: compiler request -> profile -> source/semantic validation -> dependency inventory -> VM object inventory -> capability/security checks -> target fitment -> compile report.

The Compiler Manager is a completeness gate and rejects missing requirements rather than inventing them.
