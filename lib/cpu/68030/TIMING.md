# Motorola 68030 Timing

Tracked events:

- instruction fetch;
- I-cache access;
- decode;
- effective-address generation;
- integer execution;
- D-cache access;
- MMU/ATC translation;
- burst bus cycle;
- coprocessor cycle;
- exception/interrupt;
- completion.

The exact microcycle behavior is profile-specific and is not replaced with a modern superscalar abstraction.
