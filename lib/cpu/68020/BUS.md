# Motorola 68020 Bus

The 68020 provides a 32-bit address/data system interface with dynamic bus sizing.

SLeeLa bus transactions include:

- address;
- function-code/privilege context;
- read/write;
- transfer size;
- data;
- byte enables;
- bus-cycle state;
- acknowledge;
- bus error;
- retry/arbitration state.

Bus arbitration and DMA remain system-level resources.
