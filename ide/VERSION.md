# SLeeLa IDE Version

Current development version: **0.4.0-dev**

- 0.1.0-dev — four-language IDE contract and IntelliJ interoperability foundation.
- 0.2.0-dev — SLeeLa lexer/parser/PSI integration in the optional IntelliJ plugin.
- 0.3.0-dev — compiler diagnostics, native editor model, project tree, tab group,
  command registry, and the first SLeeLa-authored native workbench shell.
- 0.4.0-dev — native File/Edit/View/Navigate/Code/Run/Tools/Help menu groups,
  action toolbar, and SLeeLa/C/C++/Java language selector integrated into the
  SleelaUI workbench.
- 0.5.0-dev — complete file-dialog/filesystem, build/run process, and debugger
  service integration.
- 1.0.0 — production native IDE baseline.

IDE integration versioning is independent from the SLeeLa language and native ABI versions.
