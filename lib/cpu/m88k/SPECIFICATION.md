# Motorola 88000 Specification

## Programmer model

- 32-bit RISC architecture;
- 32 general-purpose registers;
- fixed 32-bit instruction words;
- load/store architecture;
- separate control-register space;
- integer and floating-point operations;
- delayed control-transfer behavior in the architectural model;
- explicit condition-code/control facilities.

## MC88100

The MC88100 is the original 88000 processor and uses external cache/control components in its system architecture.

## MC88110

The MC88110 extends the family with integrated cache resources and a more aggressive superscalar implementation.

## Memory management

The 88000 family includes memory-management/protection facilities through its control architecture and MMU system.
