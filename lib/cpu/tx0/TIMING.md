# TX-0 Timing

No cycle-accuracy claim is made by the baseline profile.

- **Functional mode:** deterministic semantics for implemented instructions.
- **Timed mode:** requires explicit TX-0-specific timing metadata.
- **Missing data:** report timing as unavailable rather than substituting timing from another computer.

Document the source for each timing entry and label values as documented, measured, or estimated. Host execution speed is not guest instruction timing.
