# SLeeLa Standard Library

Portable API layers for data/Unicode, math, time, files, processes, networking, security, HTTP, JSON/XML/BODI, email, databases, GUI/terminal, concurrency and testing. Domain libraries remain separately versioned: Math, Physics, Astrophysics, Chemistry, Economics, Finance, Inference/Statistics and Sociology.

Portable contracts belong here; platform-specific implementations remain behind OS adapters or explicit platform modules.
