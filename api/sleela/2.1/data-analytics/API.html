SLeeLa Data Analytics API

The data-analytics shelf provides bounded native C operations for numeric data sets within the SLeeLa science model.

Operations

  • sum, mean, min, max
  • variance and population stddev
  • correlation for two equally sized data sets with non-zero variance

Limits

A data set contains 1–1024 finite numeric values. The API validates inputs before calculation and does not read files, execute SQL, or open network connections.

BODI

Data analytics is represented as the data-analytics discipline inside a kind="science" BODI project, alongside mathematics, physics, chemistry, and other scientific disciplines.
