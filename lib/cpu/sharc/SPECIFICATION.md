# SHARC DSP Specification

The selected device profile defines ISA generation, word and address widths, register inventory, arithmetic formats, memory map, peripherals, and timing. Model capabilities can include floating-point and fixed-point arithmetic, SIMD/vector-style operations on applicable generations, multiply-accumulate, circular buffers, zero-overhead loops, DMA, and independent instruction/data movement. Features are enabled only when supported by the chosen SHARC generation.
