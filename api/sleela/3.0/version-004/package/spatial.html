SLOctree #sleela 2.5 (lib/spatial/SLOctree.sleela)

SLOctree class

A sparse point-region octree over an integer cube [0, size)^3, where size is rounded up to a power of two. Each node covers an axis-aligned cube and either is a leaf (holding at most one point payload) or has up to eight children, one per octant. insert descends, subdividing only along the path to the inserted point, so empty space costs nothing. Every scan (count, collectRegion) prunes whole subtrees whose cube does not overlap the query, turning an O(size^3) volume walk into a walk of only the occupied subtrees. Suited to sparse volumes, point clouds, frustum/region queries, and ray traversal. A node is both the tree handle and a subtree root.

Carries the standard Metadata Class record — eleven catalogued provenance attributes (version, id, author, date, copyright, trademark, corporation, origin, birth date, science rating, national schedule) with matching get/set accessors. These are omitted from the tables below for brevity.

SLSpatialHash #sleela 2.5 (lib/spatial/SLSpatialHash.sleela)

SLSpatialHash class

A sparse 3D spatial hash grid. Continuous points are quantized to integer cells of a fixed cellSize, and each occupied cell maps to a String payload (an id or label). Buckets are a fixed number of parallel native arrays keyed by a mixed hash of the cell coordinates, so insert and point lookup are near O(1) and a "what is near P" scan only visits the 27 cells of the 3x3x3 neighbourhood around P rather than the whole volume. Suited to sparse worlds, point clouds, and broad-phase collision. Negative coordinates are handled with floor division and a non-negative bucket index.

Carries the standard Metadata Class record — eleven catalogued provenance attributes (version, id, author, date, copyright, trademark, corporation, origin, birth date, science rating, national schedule) with matching get/set accessors. These are omitted from the tables below for brevity.

SLVoxelGrid #sleela 2.5 (lib/spatial/SLVoxelGrid.sleela)

SLVoxelGrid class

A dense 3D grid of int cells stored in a single flat, contiguous native array indexed by i = x + y*width + z*width*height (row-major, x fastest). This is the "integrated" alternative to a nested int array of arrays of arrays: one allocation, cache-linear scans, and no per-axis pointer chasing. Cells carry a caller-chosen empty sentinel (default 0) so a scan can skip unset space. Suited to dense volumes where most cells are addressed.

Carries the standard Metadata Class record — eleven catalogued provenance attributes (version, id, author, date, copyright, trademark, corporation, origin, birth date, science rating, national schedule) with matching get/set accessors. These are omitted from the tables below for brevity.
