# Java Integration Example

Java is the JVM integration example.

The host Java tooling remains authoritative for Java semantics. SLeeLa integration recognizes Java modules/source roots, exposes connector/runtime entrypoints and navigates between SLeeLa declarations and Java bridge classes where metadata declares the relationship.

Relevant repository areas include connector/java, gui/java, audio/java and java28/src/java.
