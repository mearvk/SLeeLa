SLRrs #sleela 3.0 (lib/rrs/SLRrs.sleela)

SLRrs class

SLeeLa mirror of RRS -- Reasonable Responsibility Solidity (sllmrrs_ in artificial-intelligence/rrs/rrs.h). Three congruent models are chained feed-forward over a ternary signal: 1 = AFFIRM, 0 = ELIMINATE, 2 = POWER_ADD. Stage 1 is conjunctive (strict AND), stage 2 is the reasonable-responsibility prelude, stage 3 is the solidity culmination. RRS subtracts faith: any faith or trial premise is forced to ELIMINATE. It ships no weights; the ternary net is a tiny conjunctive accumulator.

Carries the standard Metadata Class record — eleven catalogued provenance attributes (version, id, author, date, copyright, trademark, corporation, origin, birth date, science rating, national schedule) with matching get/set accessors. These are omitted from the tables below for brevity.
