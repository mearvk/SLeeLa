BankAccount #sleela 2.5 (lib/citizen/BankAccount.sleela)

BankAccount class

Defines BankAccount, the civic-finance Master Class — the quiet place a Citizen's money goes to be anxious. It models a single banking relationship: who you bank with, the routing + account numbers that get the money there, and the balance that is somehow always lower than you expect. BankAccount is a NATURAL / LOADABLE MODULE sharing the common module contract (load / loaded / moduleName / describe). It is a sidecar owned by Citizen and carries the real banking details: a 9-digit ABA routing number (the first two digits of which the Federal Reserve uses to decide which of its twelve Districts your money reports to) and an account number. It holds balance state in whole cents to keep the pennies honest. Family: citizen. Settlement crosses an explicit bridge to the ledger and the FederalReserveID clearing fabric.

Character class

Defines Character, the central Master Class of the character package — a named actor in the Sleela economy who adopts exactly one BusinessModel and lives or dies by its monthly profit. A Character is classful by design: it is one class that composes any one of the many, many business-model classes in this package. Character is a NATURAL / LOADABLE MODULE sharing the common module contract (load / loaded / moduleName / describe). Citizen #sleela 2.5 (lib/citizen/Citizen.sleela)

Citizen class

Defines Citizen, the civic Master Class — one honest, taxpaying, coffee-drinking person as modeled by the Republic of Sleela. A Citizen is the smallest unit of a nation that still complains about the weather. Citizen is a NATURAL / LOADABLE MODULE sharing the common module contract (load / loaded / moduleName / describe) with the other /lib Master Classes, so a loader can treat it uniformly. It composes three sidecar records that it owns and keeps consistent: an Industry affiliation (what they do for a living), a BankAccount (where the money quietly leaves from), and a FederalReserveID (how the central bank pretends to know them personally). A Citizen is, famously, able. It can be born, employed, paid, taxed, retired, and — on a good day — content. It holds civic state only; the paperwork is performed by the sidecar classes in this package. The runnable orchestration example lives in citizen/sleela/CitizenDemo.sleela. Family: citizen. Civic data crosses an explicit bridge to the ledger.
