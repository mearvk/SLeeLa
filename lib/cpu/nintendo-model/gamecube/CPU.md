# Nintendo GameCube — CPU Reference

## Hardware Profile

| Field | Reference |
|---|---|
| System | Nintendo GameCube |
| CPU | IBM Gekko, PowerPC-derived |
| CPU clock | 485 MHz |
| Main RAM | 24 MB 1T-SRAM |
| Additional RAM | 16 MB DRAM |
| Launch | 2001 |
| Launch MSRP | $199.99 US |
