# Nordshrift examples

Examples and integration exercises for the Nordshrift development item. Add a short description of its role and prerequisites as the implementation becomes available.

## Contents

Place focused, runnable examples for this area in this directory. Prefer one example per subdirectory when an example has multiple source or support files.

## Example requirements

- Include the complete source and any small, non-sensitive test data needed to run the example.
- Document prerequisites, build/compile commands, and run commands.
- State the expected behavior or output and how to verify it.
- Keep reusable library implementation code in its owning source directory; this folder is for examples and demonstrations.
- Do not include credentials, private keys, personal data, or generated build artifacts.
