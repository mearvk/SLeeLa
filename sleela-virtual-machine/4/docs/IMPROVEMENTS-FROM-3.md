# Improvements from SLVM/3 to SLVM/4

| Area | /3 | /4 |
|---|---|---|
| Execution | Verified isolated execution | Authenticated distributed execution |
| Linking | Verified artifacts | Cross-runtime compatibility negotiation |
| Objects | Local VM objects | Explicit remote object IDs and leases |
| Broker | Security foundation | Freshness, leases, remote GUI/object lifecycle |
| Capabilities | Local authority | Scoped expiring delegation |
| Resolver | Policy concept | Authenticated, observable resolution boundary |
| Observability | Tamper-evident local chain | Correlated distributed audit chain |
| JVM | External integration hooks | Structured object-broker interoperability |
| Certificates | Execution trust | Peer/runtime trust exchange |
| Attestation | Local evidence | Distributed execution evidence |
