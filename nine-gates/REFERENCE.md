## The fictional work in brief

The allusion is to a fictional occult book usually rendered in English as **_The Nine Gates of
the Kingdom of Shadows_**. It is a plot device, not a real historical grimoire:

- It originates in Arturo Pérez-Reverte's 1993 novel **_El Club Dumas_** (_The Club Dumas_) and
  was adapted in Roman Polanski's 1999 film **_The Ninth Gate_**.
- Within the story, the book is famous for a set of **nine engravings** (plates). The central
  conceit is that only a few surviving copies exist and that their engravings differ in a
  deliberate, meaningful way — some plates carry a hidden mark attributing them to a different,
  darker hand than the book's nominal engraver. Comparing the copies — and reading the combined
  set of plates as a sequence — drives the plot.
- The number **nine** and the **gate / passage** motif are the elements this project borrows.
  Those are generic ideas (not themselves protectable); the specific engravings are not borrowed.

## Why this project uses only original art

Because the engravings are protected artwork, this directory ships **original emblems** instead of
the real plates. The two should not be confused:

| | The fictional grimoire's engravings | This project's emblems |
|---|---|---|
| Origin | the cited novel / film | authored for this repository |
| Status | copyrighted; not reproduced here | original; shipped in [`images/`](./images) |
| Relationship | the allusion/inspiration | a new, independent nine-part set |

The project's nine gates (**The Threshold, The Lantern, The Bridge, The Mirror, The Keystone, The
Tide, The Ember, The Compass, The Horizon**) are an original sequence and do **not** correspond
one-to-one to the fictional grimoire's plates.
