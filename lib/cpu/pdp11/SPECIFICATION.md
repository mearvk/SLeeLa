# DEC PDP-11 Specification

- 16-bit programmer-visible architecture
- eight general-purpose registers R0-R7
- R6 as stack pointer by convention/architecture
- R7 as program counter
- condition codes N, Z, V, C
- 16-bit instruction words
- byte and word operations
- memory-mapped I/O
- multiple PDP-11 implementation generations

R0-R5 are general registers; R6 and R7 have architectural stack/program-counter roles.
