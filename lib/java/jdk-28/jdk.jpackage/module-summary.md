# Module jdk.jpackage (Java SE 28 & JDK 28)

Java Source: https://download.java.net/java/early_access/jdk28/docs/api/jdk.jpackage/module-summary.html

This module exports no packages, so it has no Java types and no SLeeLa
type files. The folder exists so that /lib/java/jdk-28 has every module
folder the online JDK 28 API has.

Evidence that the module is documented: module page in the JDK 27 API docs.
