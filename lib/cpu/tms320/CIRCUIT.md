# Texas Instruments TMS320 Circuit Model

Functional DSP model, not transistor-level reconstruction. Configurable blocks: program fetch/decode, profile-specific register files, address-generation units, multiplier/MAC unit, accumulator/ALU, program-memory interface, data-memory interface, circular/repeat-loop control, interrupt/peripheral interface, clock/pipeline sequencing. SLCoupler models fetch-to-decode, address-to-data-memory, multiplier-to-accumulator, memory traffic, loop-control-to-fetch, and peripheral/DMA-to-system-bus paths.
