# SLeeLa IDE Version

Current development version: **0.3.0-dev**

- 0.1.0-dev — IntelliJ integration foundation and four-language project model.
- 0.2.0-dev — SLeeLa lexer/parser/PSI integration.
- 0.3.0-dev — compiler diagnostics (native `sleela check` bridge), syntax
  highlighting from `SLEELA.syntax`, file-type branding, commenter, color
  settings page; full developer action surface (branded SLeeLa main menu,
  editor/project-view context menus, toolbar buttons, keyboard shortcuts),
  Run/Check/Build/Transpile/Version actions, a SLeeLa run configuration type
  with a context producer, a branded SLeeLa tool window, and New → SLeeLa File
  templates. (indexing, completion, navigation: in progress)
- 0.4.0-dev — build/run/test integration.
- 0.5.0-dev — debugger/DAP integration.
- 1.0.0 — production IDE integration baseline.

IDE integration versioning is independent from the SLeeLa language and native ABI versions.
