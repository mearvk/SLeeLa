# True or False

A **true** statement matches what you see.
A **false** statement does not match.

Look at the toy shelf (the ball is in the red box).

| I say | true or false? |
|-------|----------------|
| The ball is in the red box. | true |
| The ball is in the blue box. | false |
| The block is on the shelf. | true |

Two little words help:

- **and** means both are true. "The ball is in the red box **and** the book is in
  the blue box." Both true, so **true**.
- **not** flips it. "**NOT** (the ball is in the blue box)." The ball is not there, so
  this is **true**.

**Try it:** Say one true thing and one false thing about the room you are in.
