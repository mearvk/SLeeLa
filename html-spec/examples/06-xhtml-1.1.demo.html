XHTML 1.1 (2001) — Use-Case Demonstration

Date: 2026-10-25

XHTML 1.1 is module-based XHTML: the XHTML 1.0 Strict vocabulary, minus the HTML-compatibility allowances, plus the Ruby Annotation module. Each example states whether it performs as expected in a modern browser: ✓ Yes, or ✗ No.

Use case 1 — Ruby annotation (simple)

Title: Furigana over kanji  |  Date: 2026-10-25

漢字 (kanji) means "Chinese characters."

Performs as expected: ✓ Yes for ruby/rt/rp — carried into HTML5 and widely supported. ✗ No for <rb> — obsolete in the modern standard (put the base text directly in <ruby>).
