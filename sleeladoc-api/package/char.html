SLChar #sleela 3.1 (lib/char/SLChar.sleela)

SLChar class

Helpers over the char type of SLEELA.syntax section 45: a char is an unsigned 16-bit UTF-16 code unit held in an integer slot. The methods classify and map ASCII and Latin-1 chars, convert between chars, codes and digits, and recognize surrogates. Chars beyond Latin-1 need the Unicode tables and are the business of the Java text tier.

Carries the standard Metadata Class record — eleven catalogued provenance attributes (version, id, author, date, copyright, trademark, corporation, origin, birth date, science rating, national schedule) with matching get/set accessors. These are omitted from the tables below for brevity.
