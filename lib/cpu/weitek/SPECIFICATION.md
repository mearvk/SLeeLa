# Weitek POWER Specification

## Programmer state

The Weitek POWER family provides a RISC-oriented processor model with integer and floating-point execution resources.

SLeeLa models:

- integer registers;
- floating-point registers;
- program counter;
- condition/control state;
- implementation-specific system state.

## Execution

The architecture emphasizes high-performance arithmetic and floating-point processing with load/store memory operations and implementation-specific pipeline resources.
