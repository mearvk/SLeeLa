# SLeeLa Audio and Video API

Native-frame foundation for live audio/video capture, analysis, visualization, transforms and future AI integration.

- Audio: PCM float, level/peak/RMS, spectrum extension.
- Video: Gray8/RGB24/RGBA32, luminance/edge/motion analysis.
- Listener: consumes timestamped frames.
- Transform: derives frames.
- AI hook: future provider boundary.
- BODI/XML: declarative processing configuration.
