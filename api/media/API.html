SLeeLa Audio and Video API

The media API treats audio and video as timestamped native frames. It provides lightweight signal analysis, listeners, transforms and an explicit future AI hook without making a particular codec, device framework or AI engine part of the base ABI.

Audio

Audio frames use PCM float samples and expose level, peak, RMS and an extension point for frequency-spectrum data.

Video

Video frames support Gray8, RGB24 and RGBA32 native references. The analyzer exposes dimensions, luminance, edge density and a reserved motion value.

Processing

Listeners and transforms operate on frames. XML processing is declarative and remains allow-listed.

AI extension

SLMediaAIHook is a provider boundary for future audio/video AI input and output and is adjacent to the native frame structures.
