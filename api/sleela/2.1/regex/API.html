SLeeLa Regex API

Draft: Regex API 1.0.0 — Sleelvac 1.5 — SLeeLa syntax 1.3.

Four levels

  1. Find: contains, starts, ends, exact.
  2. Shape: word, digit, space, any, repetition.
  3. Structure: choice, group, range, optional, capture.
  4. Expression: anchors, Unicode properties, bounded expressions, named captures, advanced assertions.

Design principle

Ask for the text match directly. SLeeLa hides unnecessary regex punctuation while preserving deterministic, documented matching semantics.

Example

match("report.txt", "ends .txt")
match("2026", "exact digit{4}")
