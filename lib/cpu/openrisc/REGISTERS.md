# OpenRISC 1000 Registers

The profile defines the general-purpose register set, PC, status/supervision state, exception/interrupt state, and special-purpose registers (SPRs). Extension registers for floating point, DSP, debug, MMU, or other features exist only when the profile enables them. Register widths, reset values, SPR numbering, reserved bits, and privilege checks must match the selected OR1K revision and implementation.
