## Summary

HTML 5.2 was the final version of HTML published as an independent W3C Recommendation. After this, the W3C and WHATWG signed a **2019 agreement** under which the single **WHATWG HTML Living Standard** became the authoritative version of HTML, and the W3C stopped publishing its own separate HTML specs.

## Notable changes

- Added the native `<dialog>` element (modal/non-modal dialogs)
- Allowed multiple `<main>` elements (where all but one are hidden)
- Integrated the **Payment Request API** hooks and updated security requirements (e.g. around `<iframe>` sandboxing, Content Security Policy references)
- Removed `<keygen>`, `<menuitem>`, and `inputmode` (at the time); numerous conformance fixes

## Significance

Marks the end of the W3C's parallel "REC" track for HTML. From 2019 onward, the canonical specification is the WHATWG Living Standard (see `10-html-living-standard.md`). The source archived here is the W3C HTML WG's Bikeshed source that generated the 5.x RECs.
