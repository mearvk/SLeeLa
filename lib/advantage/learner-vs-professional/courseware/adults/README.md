# Courseware: Adults

Precise lessons on logic and processes, with worked problems that end in the
Advantage(TM) Sequitur onion model.

Units (all five are written, each with exercises and an answer key):

1. Propositional logic: connectives, truth tables, equivalences. **Written:** [unit-01-propositional-logic.md](./unit-01-propositional-logic.md)
2. Predicates and reasoning: quantifiers, valid and invalid inference. **Written:** [unit-02-predicates-and-inference.md](./unit-02-predicates-and-inference.md)
3. Processes and algorithms: sequence, selection, iteration, correctness. **Written:** [unit-03-processes-and-algorithms.md](./unit-03-processes-and-algorithms.md)
4. Complexity basics: cost of a procedure as input grows. **Written:** [unit-04-complexity-basics.md](./unit-04-complexity-basics.md)
5. Applied: model a decision as onion layers and run it in SLeeLa. **Written:** [unit-05-applied-onion-decisions.md](./unit-05-applied-onion-decisions.md)

Any `.sleela` example added here should carry the Metadata Class metapattern.
