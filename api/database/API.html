SLeeLa Native Database Connector

Cross-platform database connectivity vocabulary for SLeeLa applications on Linux, Windows 8+, and macOS.

Database families

PostgreSQL, MySQL, MariaDB, SQLite, Microsoft SQL Server, Oracle Database, and ODBC-compatible databases.

Operations

validate, connect, ping, query, execute, begin, commit, rollback, close.

Native API

sleela_database_validate() performs bounded configuration validation. sleela_database_kind_name() returns the stable family name.

Platform adapters

Linux: linux/dbctl.sh. macOS: macos/dbctl.sh. Windows 8+: windows/DbCtl.ps1.

Security

Passwords are referenced through environment variables or an operating-system credential facility, not command-line arguments. Applications should use parameter binding for SQL values. Client/driver installation is explicit and platform-managed.
