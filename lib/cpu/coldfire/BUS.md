# Motorola ColdFire Bus

ColdFire systems use embedded-system bus/interconnect implementations appropriate to the selected core and SoC.

SLeeLa transactions contain:

- address;
- operation;
- transfer size;
- data;
- byte enables;
- memory attributes;
- privilege;
- response/error;
- master identity.

DMA, peripherals, and memory controllers remain system-level components.
