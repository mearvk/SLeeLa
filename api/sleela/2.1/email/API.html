SLeeLa Email Facade API Reference

sleela_email_message_t

Configures SMTP endpoint, local source address, TLS mode, optional AUTH PLAIN credentials, and RFC-style message fields.

Endpoint fields

  • smtp_host: DNS name or IP of the SMTP server.
  • smtp_port: SMTP listener port.
  • helo_name: EHLO identity.
  • local_bind_host: optional local DNS name/IP used for socket binding.

TLS

NONE, STARTTLS, and IMPLICIT are supported. TLS connections require certificate validation against the OpenSSL trust store and verify the SMTP DNS name or IP.

Submission

sleela_email_send performs SMTP greeting, EHLO, optional TLS, optional AUTH PLAIN, MAIL FROM, RCPT TO, DATA, and QUIT.

Result

The function returns nonzero on successful SMTP acceptance and zero on failure, with a bounded diagnostic written to error_text.
