# Fairchild Clipper Specification

## Programmer state

- 32-bit general-purpose register set
- program counter
- processor status/control state
- floating-point facilities in applicable implementations

## Instruction model

Clipper uses fixed-width RISC instructions with register-oriented operations, load/store behavior, and delayed control-transfer semantics.

Memory-management, cache, and floating-point resources vary by implementation.
