# novice — first contact with the model

Examples for a reader meeting the `advantage` model for the first time. They
favor outcomes over controls and keep to a single idea at a time.

| Topic | Folder | Example | Shows |
|-------|--------|---------|-------|
| The onion model | [`onion-model/`](onion-model/) | `onion-primer.sleela` | the layered dividend process end to end — the user's and developer's models, dynamic update + restitute |
| Consumer outcomes | [`consumer-outcomes/`](consumer-outcomes/) | `consumer-example.sleela` | a consumer who wants the result, not the dials: nudges three plain controls (grow/shrink/rethink) to a net advantage of 30 |
| Network trades | [`network-trades/`](network-trades/) | `lumber-trade.sleela`, `cement-trade.sleela` | scout a venue network, pick the best buy/sell, negotiate a fair price, and emit a receipt — the entry rungs (lumber, cement) with no frictions |

Run from the repository root:

```sh
./working-binaries/sleela run lib/advantage/examples/novice/onion-model/onion-primer.sleela
```
