AlphabetBuilder #sleela 2.5 (lib/alphabet/AlphabetBuilder.sleela)

AlphabetBuilder class

Defines AlphabetBuilder — the syntax 1.8+ way to assemble a custom Alphabet without declaring a subclass. Where the classic path is "subclass Alphabet and override compose()", the builder lets a user of Sleela compose a writing system inline using one-line Letter constructors and `let`-inferred locals: let b = new AlphabetBuilder("Runic"); b.vowel("A"); b.consonant("B"); ... < a fully formed Alphabet > let alpha = b.build(); Each add() builds a Letter with `new Letter(glyph, order, vowel)` (the 1.8 constructor) and hands it to Alphabet.appendLetter. The builder is the ergonomic, subclass-free front door the 1.8 surface makes possible. Family: alphabet. Composes Alphabet + Letter (1.8 constructors).

ArabicAlphabet class extends Alphabet

ArabicAlphabet — the 28-letter Arabic script (Alif..Ya). Like Hebrew, Arabic is an ABJAD: the letters are consonants and short vowels are written with optional diacritics, so each letter here is a consonant. Three letters (Alif, Waw, Ya) double as long-vowel carriers, but as letters they remain consonantal, so the alphabet's vowel count is honestly zero. A concrete Alphabet: override compose() to append its letters in order. Call begin("Arabic") to build it. Family: alphabet.

Letter #sleela 2.5 (lib/alphabet/Letter.sleela)

Letter class

Defines Letter, a single glyph in an Alphabet — the symbol, its position in the written order, and whether it is a vowel. The humblest, most important class a user of Sleela will ever meet, because everything written is written out of these. Letter is a NATURAL / LOADABLE MODULE sharing the common module contract (load / loaded / moduleName / describe). It holds glyph state only; an Alphabet owns an ordered run of Letters. Syntax 1.8+: Letter now also offers a one-line CONSTRUCTOR — `new Letter(glyph, order, vowel)` — so a glyph can be built in a single expression (`let a = new Letter("A", 1, true);`) instead of the load()+set() two-step. The two-step contract (load / set) is retained unchanged, so every existing 1.3 caller — including Alphabet.append()'s `new Letter(); load()` — keeps working: a zero-argument `new Letter()` is still valid under 1.8. Family: alphabet.

Theme #sleela 2.5 (lib/alphabet/Theme.sleela)

Theme class

Defines Theme, the base Master Class that binds the three things this package is about — a Palette of Colors, role colors (background, foreground, accent), and an Alphabet — into one coherent, user-facing look. A Theme is what a user of Sleela actually sees. A concrete theme is created by subclassing Theme and overriding dress(), which fills in the palette and role colors. The base owns the role plumbing, contrast checking, and the loadable-module contract, mirroring the base/subclass pattern used by Alphabet and the lib/compiler front ends. Theme is a NATURAL / LOADABLE MODULE sharing the common module contract (load / loaded / moduleName / describe). Family: alphabet.
