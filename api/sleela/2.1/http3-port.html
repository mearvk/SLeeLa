SLeeLa HTTP 3.0 Extended Port API

The HTTP 3.0 packet envelope carries a 160-bit logical port identifier supporting exactly 10^48 distinct values: 0 through 10^48-1.

Native C API

  • http3_port_from_decimal() — parse an exact decimal logical port.
  • http3_port_to_decimal() — return the exact decimal representation.
  • http3_port_from_u64() — initialize a logical port from a conventional integer.
  • http3_port_is_valid() — enforce the 10^48 namespace boundary.
  • http3_port_increment() — advance a logical port without overflow past the namespace.
  • http3_port_encode() / http3_port_decode() — 20-byte network-order representation.

Packet API

  • http3_envelope_set_port_decimal() — set the actual logical port and reseal the packet MAC.
  • http3_envelope_set_port_u64() — set a conventional port value and reseal the packet MAC.

Wire format

Text packets carry the decimal PORT token. Binary packets carry a 20-byte PORT field immediately after REQUEST-ID. PORT is part of the canonical DIGEST input, so the protected packet cannot be changed to a different port without invalidating its authentication tag.
