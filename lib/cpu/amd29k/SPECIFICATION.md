# AMD 29000 Specification

## Programmer state

- 32-bit integer execution
- large logical register space
- global and local/register-window organization
- program counter and control state
- optional floating-point facilities by implementation

The architecture emphasizes compiler-managed register usage and efficient procedure calls.

## Facilities

- integer ALU
- shifts and logical operations
- multiply/divide support
- load/store
- branches and delayed control transfer
- register-window management
- exceptions and interrupts
- implementation-dependent caches/MMU/FPU
