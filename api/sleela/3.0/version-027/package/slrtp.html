SLRTPAdvice #sleela 3.0 (lib/slrtp/SLRTPAdvice.sleela)

SLRTPAdvice class

An SLRTP advice -- the action taken at the join points its pointcut selects, akin to Java/AspectJ before / after-returning / after-throwing / around advice. Because the SLeeLa semantic checker is nominal and does not upcast, advice is DATA-DRIVEN rather than subclassed: an advice carries a pointcut plus an action code, and the processor applies the built-in action when the advice fires. The built-in actions cover the common cross-cutting concerns (tracing, counting, and around short-circuit / return-substitution); the join point it receives is mutable, so an around advice can decline to proceed or rewrite the return value.

SLRTPProcessor #sleela 3.0 (lib/slrtp/SLRTPProcessor.sleela)

SLRTPProcessor class

The Sleela Retrouval Tactical Processor -- SLRTP's weaver and dispatcher, akin to a Java/Spring AOP proxy that runs registered advice around a call. Because SLeeLa has no bytecode weaver, interception is EXPLICIT: a caller wraps a method body with runBefore / runAround / runAfterReturning / runAfterThrowing, passing a join point. The processor finds every registered advice whose pointcut matches and fires it in registration order; an around advice may short-circuit the real call (SKIP) or rewrite its result (SUBSTITUTE). The processor keeps a bounded trace log so a program or test can inspect what fired without reading stdout.

Carries the standard Metadata Class record — eleven catalogued provenance attributes (version, id, author, date, copyright, trademark, corporation, origin, birth date, science rating, national schedule) with matching get/set accessors. These are omitted from the tables below for brevity.
