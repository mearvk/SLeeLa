# Motorola ColdFire CPU

SLeeLa models Motorola ColdFire as a distinct 68K-derived embedded architecture rather than treating it as another MC680x0 implementation. ColdFire uses a variable-length instruction set derived from 68K while simplifying and restructuring the execution architecture for embedded systems.

## Profiles

- ColdFire V1
- V2
- V3
- V4
- V4e

Optional FPU, MMU, MAC/DSP, cache, and bus features remain profile-specific.
