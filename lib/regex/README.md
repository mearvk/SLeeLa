# SLeeLa Regex Library

The regex library family is the SLeeLa-facing object model for the native regex subsystem in make/regex/.

Each public object is kept in its own .sleela source file for indexing, testing, documentation, and independent evolution.

Native C/C++ code is reached only through the documented bridge. The SLeeLa object model remains the language-facing contract.
