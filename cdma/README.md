# CDMA

**SLeeLa CDMA Foundation**

The `/cdma` directory is reserved for SLeeLa's CDMA (Code Division Multiple Access) work: a common place to describe channels, codes, spreading sequences, and the shared-medium exchange of information between SLeeLa components.

The name **CDMA** is intentionally retained as the project directory name.

## Status

Initial, reserved foundation. Concrete specifications, source, and tests should be added only with explicit design and review.
