# SLeeLa HTTP 9.0 — Status

HTTP 9.0 is an experimental SLeeLa generation, not an IETF HTTP/9 standard.

## Present

- HTTP 9.0 C/C++ protocol implementation;
- public C/C++ headers;
- explicit specification and configuration;
- negotiation C/C++ implementation;
- syntax-check build;
- common logical-port and DOWNLOAD contracts.

## Verification targets

Conformance should cover configuration errors, bounded metadata, malformed packets, negotiation and explicit fallback, unsupported versions, replay/security policy where applicable, and clean lifecycle behavior.
