Date: 2026-10-25

Use case 10 — Embedded Java applet

Title: An applet with a parameter  |  Date: 2026-10-25

Performs as expected: ✗ No — <applet> is obsolete and no longer executes; use <object>/<embed> or modern web technology.

Summary: HTML 3.2's structural additions (div, tables, image maps, sub/sup, dfn, small) perform as expected. Its presentational additions (center, font, strike, u-as-underline, big) and <applet> do not — CSS and modern embedding replaced them.
