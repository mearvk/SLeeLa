SLMoralCapacitor #sleela 2.5 (lib/moral-capacitor/SLMoralCapacitor.sleela)

SLMoralCapacitor class

Defines SLMoralCapacitor(TM) — the ethical gate every /lib library can place in front of a consequential operation. Like an electrical capacitor it accumulates charge and only discharges when enough has built up; here the charge is moral justification contributed by ethical frameworks (deontology, utilitarianism, virtue, beneficence, consent) and the discharge is permission to proceed. An operation runs only when stored charge reaches the policy threshold AND no absolute red line (SLMoralVeto) is tripped. Lifecycle: configure() -> appraise(operation) charges from the frameworks and arms vetoes -> evaluate(threshold) returns an SLMoralVerdict (PERMIT / DEFER / DENY) -> discharge() resets the stored charge so the capacitor is reusable. Family: moral-capacitor. Composes SLMoralCharge, SLMoralVeto, SLMoralFramework, SLMoralPolicy; returns SLMoralVerdict.

SLMoralCertificateAuthority #sleela 2.5 (lib/moral-capacitor/SLMoralCertificateAuthority.sleela)

SLMoralCertificateAuthority class

Defines SLMoralCertificateAuthority — the issuer of a Certificate of Morals(TM). Given a product name and a live Moral Capacitor (its policy and armed red-line set), the authority mints an SLMoralCertificate: it records the moral posture, assigns a serial and validity span, computes a deterministic seal over the certificate's canonical body, and applies it. The same authority re-verifies a certificate by recomputing the seal, so a Guard can trust that a certificate was issued here and not altered. The seal is a deterministic fold over the canonical body keyed on the authority's name — a self-contained, reproducible integrity tag. In production it is hardened by signing the body with lib/crypto SLDigest + SLSignature under the authority's key; this class keeps the issue/verify contract stable regardless of which seal backend is linked. Family: moral-capacitor. Issues/verifies SLMoralCertificate; reads SLMoralCapacitor + SLMoralPolicy.

SLMoralCharge #sleela 2.5 (lib/moral-capacitor/SLMoralCharge.sleela)

SLMoralCharge class

Defines SLMoralCharge — the stored moral charge of a Moral Capacitor(TM). Charge is the signed sum of per-framework contributions: each ethical framework that endorses the operation adds charge, each that objects subtracts it. Charge is bounded by a maximum (a capacitor has finite capacity) and floored at zero on the discharge decision (negative net charge is simply "no moral basis"). The charge keeps per-framework attribution so a verdict can report which lens contributed what. Family: moral-capacitor. Held by SLMoralCapacitor.

SLMoralCodeGuard class

Defines SLMoralCodeGuard — the Guard of the Moral Code: the enforcement that a SLeeLa software product actually INCLUDES the moral code it claims. Before a product is permitted to run or ship, the guard checks that it (1) embeds a live Moral Capacitor(TM), (2) presents a Certificate of Morals(TM) that is well-formed, (3) was sealed by a trusted authority and verifies against it, (4) is within its validity span, and (5) attests a posture consistent with the embedded capacitor (same policy threshold, red lines armed). Family: moral-capacitor. Verifies SLMoralCertificate via SLMoralCertificateAuthority; inspects SLMoralCapacitor.

SLMoralFramework #sleela 2.5 (lib/moral-capacitor/SLMoralFramework.sleela)

SLMoralFramework class

Defines SLMoralFramework — the catalogue of ethical lenses the Moral Capacitor(TM) charges from. Each framework is a named way of judging an operation's rightness, drawn from the coorenagraph moral vocabulary: deontology (duties/rules), consequentialism/utilitarianism (outcomes), virtue ethics (character), beneficence (do good / avoid harm), and consent/autonomy (respect the affected party's will). A framework contributes a small signed charge to the capacitor: positive when it endorses the operation, negative when it objects. This is the vocabulary bridge: the frameworks name the same ethics the coorenagraph package defines (Deontology, Utilitarianism, VirtueEthics, Beneficence), made evaluable as capacitor charge. Family: moral-capacitor. Bridges coorenagraph; charges SLMoralCapacitor.

SLMoralOperation class

Defines SLMoralOperation — the thing the Moral Capacitor(TM) judges. An operation is described by who performs it (actor, e.g. "vm" / "os" / "machine"), the action verb (e.g. "allocate", "erase", "spawn", "boot"), the target it affects (e.g. "guest-memory", "/dev/sda"), the scope (e.g. "process", "disk", "host"), whether it is reversible, and whether the affected party has consented. These fields are what the frameworks appraise and what the veto set tests. Keeping the operation an explicit object (rather than loose arguments) means a verdict and a ledger entry can name exactly what was judged. Family: moral-capacitor. Evaluated by SLMoralCapacitor.
