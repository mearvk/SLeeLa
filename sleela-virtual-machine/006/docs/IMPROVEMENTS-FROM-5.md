# Improvements from SLVM/5 to SLVM/6

| Area | /5 | /6 |
|---|---|---|
| Evidence | Durable checkpoints | Continuous lineage |
| Attestation | Build/policy evidence | Multi-party hooks |
| Recovery | Checkpoint recovery | Verified migration |
| Transactions | Explicit context | Epoch continuity |
| Objects | Leases | Revocation epochs |
| Resolver | Provenance | Provenance continuity |
| Certificates | Rotation policy | Lifecycle evidence |
| Compatibility | Negotiated | Migration-time verification |
| Isolation | Fault containment | Failure-domain isolation |
