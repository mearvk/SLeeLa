# Sleelavirin™ Provenance

Security decisions are more useful when their source can be reconstructed.

Record, where available:

- author/package identity;
- source repository or release identifier;
- scanner/provider;
- database/rule version;
- rule source;
- artifact digest;
- signing identity;
- scan time;
- platform and architecture;
- relevant configuration.

Provenance is evidence metadata, not a guarantee of safety.
