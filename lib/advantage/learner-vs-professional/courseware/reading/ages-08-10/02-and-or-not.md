# And, Or, Not

Three little words, big power.

- **AND**: true only when **both** parts are true.
- **OR**: true when **at least one** part is true.
- **NOT**: flips true to false and false to true.

Our shelf has the ball in the red box and the book in the blue box.

| statement | answer |
|-----------|--------|
| ball in red box AND book in blue box | true |
| ball in red box AND book in red box | false |
| ball in blue box OR book in blue box | true |
| NOT (book in red box) | true |

## Checking with a friend

You and a friend each write where every thing is, without peeking. Then compare.

- Same answer? Put a tick.
- Different? **Both look again at that one thing.** Do not just copy.
- Done when every thing has a tick.

Grown-up programs do exactly this and print "re-observe" for the thing to look at.

**Try it:** Write 3 statements about your room using AND, OR and NOT.
Ask a friend if each is true or false.
