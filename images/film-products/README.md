# Film Products

This directory contains film-related product images and visual assets for the SLeeLa project.

## Organization

- Store film-product images and derivatives in this directory.
- Use descriptive, lowercase filenames with hyphens.
- Keep original assets separate from edited or generated derivatives when practical.
- Add attribution and licensing information for assets that require it.
- Do not commit confidential, unlicensed, or otherwise restricted material.
