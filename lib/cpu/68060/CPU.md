# Motorola 68060 CPU

SLeeLa models the MC68060 as the final major mainstream Motorola 68000-family superscalar implementation, retaining the 68K programming model while substantially increasing instruction issue, branch handling, cache capacity, and execution parallelism.

## Profiles

- MC68060
- MC68LC060 — floating-point unit removed

The 68060 remains distinct from the 68040 despite source-level compatibility.
