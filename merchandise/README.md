## Collection
1. Apparel: hoodie, T-shirt
2. Headwear: cap or beanie
3. Drinkware: mug, insulated tumbler
4. Carry: tote bag, laptop sleeve
5. Desk: notebook, sticker set, desk mat
6. Tech: phone case and laptop skin
7. Accessory: key tag

## Production guardrails
- Use vector masters and request vendor proofs at actual size.
- Keep one-color variants for embroidery, engraving, and economical printing.
- Do not use third-party platform logos or imply endorsement.
- Do not add unsupported performance, security, or compatibility claims.
- Add vendor, SKU, price, and storefront details only after real procurement is arranged.
