# SLeeLa HTTP 4.0–9.0 Native Servers

The numbered directories `4/` through `9/` now contain runnable source programs for the SLeeLa HTTP generations.

- 4: binary frame/session lifecycle, sequence validation, resumability and flow-control frames.
- 5: HTTP 4 framing plus Friends' Pack, bonus, FP update and audit extensions.
- 6: HTTP 5 framing plus consolidated application/debate fields.
- 7: semantic/assertion metadata.
- 8: handshake, subscription/radio/checker/session metadata.
- 9: identity, monitoring configuration, international metadata and Dark Band metadata.

All listeners default to loopback and require explicit network exposure. HTTP 7–9 remain application-level project protocols; their names do not assert Internet-standard HTTP versions.
