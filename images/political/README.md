# Political Image Assets

This directory contains political-themed image assets and visual materials for the SLeeLa project.

## Organization

- Use descriptive, lowercase filenames with hyphens.
- Keep original assets separate from edited derivatives when practical.
- Document each asset's purpose, source, and applicable license or attribution.
- Clearly identify illustrative, generated, archival, and documentary materials where relevant.
- Do not commit confidential or unlicensed material.
