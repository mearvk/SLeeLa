# Motorola 6809 Specification

- 8-bit data architecture; 16-bit address space
- A and B 8-bit accumulators; D is the combined A:B 16-bit view
- X and Y 16-bit index registers
- U user stack pointer; S system stack pointer
- 16-bit PC, direct-page register DP, condition-code register CC
- Variable-length instructions and rich indexed addressing
- MC6809 and externally clocked MC6809E profiles
