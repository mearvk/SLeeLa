# SLeeLa Server Edition Production Contract

## Required production path
**Holding Document → Forwarding Annotation → Nexter Colony**

Production implementations should expose forwarding success, forwarding rejection, unresolved Nexter Colony, loop/hop-limit rejection, capability rejection, bounded-resource metrics, structured audit logs, trace propagation, graceful shutdown, deterministic configuration, and health/readiness reporting.

Annotations describe intent and architecture. The Server Edition enforces runtime policy. No annotation bypasses security, capability, resource, release, or deployment controls.
