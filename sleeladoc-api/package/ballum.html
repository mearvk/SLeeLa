SLBallumEffect (lib/ballum/SLBallumEffect.sleela)

SLBallumEffect class

The catalog of Ballum transition effects a session uses to reveal a logo over a background across its fade timeline. Each effect id mirrors the native ballum_effects.h / ballum_fx_t set one-for-one; the native compositor (uiBallumLogoBlend) applies the chosen effect per frame. Effects are deliberately broad and fun: fades, wipes, iris, bars/blinds, dissolve, pixelate, slides, zoom, spotlight, ripple, checker, diamond, a radial clock wipe, and sparkle. Pick one with id() or byName(); a session passes the id to uiBallumLogoSetEffect before its fade. Family: ballum. Pure catalog; the compositing lives in native code.
