# SLeeLa `website` — airline brand sites

Each known modern airline has its own subdirectory under `lib/website/`, holding
one `.sleela` **Master Class** that builds a complete, self-contained HTML
website for that airline. These are generated by
[`generate-airlines.py`](generate-airlines.py) and follow the same model as
[`website.sleela`](website.sleela): a brand **design** (brand / base / accent
color + an energy dial) plus an ordered list of semantic **signs** (nav, hero,
feature, testimonial, cta, footer). Only the brand identity and copy change
between airlines — the sign model is shared. The output is pure String
concatenation on `OP_ADD` plus integer-to-text; no new VM opcode is required.

> Nested subdirectories stay part of the first-level `website` package: they add
> source classes but **no new package and no new facade**.

## Using one

Each class is self-contained and runnable — it prints its finished HTML:

    impl/build/sleela run lib/website/delta-air-lines/DeltaWebsite.sleela

Or embed the builder and call `build()` to get the HTML string, with
`brandName()`, `brand()`, `accent()`, `tagline()`, and `hubs()` exposing the
brand identity.
