## Scenario interpretation
The 1–30 capability scale is a game-style simulation convention. INT 19 is a hypothetical input supplied for this scenario, not a measured personal attribute. Similar values for creativity, systems thinking, technical innovation, execution, exploration, collaboration, and resilience are assumptions for the model. Sustainability and private-life measures remain unknown.

The modifier formula floor((INT - 10) / 2) yields +4 at INT 19. The invented planning index 100 + 5 × (INT - 10) yields 145 at INT 19; this is a game index, not a real-world productivity or cognition percentage.

The weighted career-leverage scenario index uses creativity (25%), systems thinking (20%), technical innovation (20%), execution (20%), exploration (10%), and collaboration (5%). With the current illustrative values, the index is 62/100. It is a planning aid, not an objective measure of a person's life.

Public-career indicators are approximate summary metrics and should be maintained against dated sources. National Geographic's Explorer profile documents Cameron's filmmaking and exploration career and three personal Oscars: https://explorers.nationalgeographic.org/directory/james-cameron.
