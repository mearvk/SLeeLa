## Summary

HTML 3.2 was the **first W3C Recommendation** for HTML, marking the handoff of HTML stewardship from the IETF to the W3C. The ambitious HTML 3.0 draft had been abandoned; 3.2 instead standardized the widely-deployed features that browser vendors (Netscape, Microsoft) had already shipped.

## Key features

- **Tables** (`<table>`, `<tr>`, `<td>`, `<th>`, `<caption>`)
- **Applets** (`<applet>`) for Java integration
- Text flow around images, superscripts/subscripts
- Presentational markup: `<font>`, `<center>`, color and alignment attributes — styling lived *in* the markup
- Dropped the math features that HTML 3.0 had proposed (deferred, eventually → MathML)

## Significance

Pragmatic consolidation of real-world browser practice. Its heavy reliance on presentational tags is exactly what later versions (and CSS) would work to undo.
